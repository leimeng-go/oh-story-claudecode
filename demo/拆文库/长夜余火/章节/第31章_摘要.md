# 第31章 曾经

**概要**：旧调小组在水围镇做客吃饭时，蒋白棉发现镇上孩子白天在上课，这在生存艰难的灰土聚居点中极为罕见。镇长田二河讲述，最早提倡正式教育的是沈柳心，他认为只有让孩子识字读书，镇民才能记得自己是谁、来自哪里，在无希望的黑暗中坚守下去；田二河承认自己当年赞同只是因为在城市废墟搬回的物品说明书上有字不认得，近年才理解沈柳心的话。他随后揭示，众人身旁呈“品”字型的三栋楼正是旧水围镇的学校，有篮球场、升旗台、宿舍、教学楼，并郑重重复“这里曾经是学校”。他主动自曝镇内矛盾：不少镇民认为学校只该供原本居民，后来的流浪者只能租地交收成、不得加入镇卫队持好武器，他担心自己死后靠威望压不住、镇子分崩离析。饭后蒋白棉打听一名黑发金眼、穿风衣戴手套的高个英俊男子，田二河派镇卫队员小狗子去问外出狩猎者。白晨不解镇长为何透露内部矛盾，蒋白棉点破他是想让水围镇搭上小组背后的大势力以求庇护，并表示会按流程上报公司、但隐去水围镇的具体位置。小狗子回报：有人见过该男子，他去了月鲁车站以北，且当时整个狩猎小队都觉得他极有魅力、忍不住想讨好他，他却冷漠地拉开距离消失在荒野。蒋白棉低语“有点奇怪”，夜色降临，酝酿许久的大雨落下。

**关键事件**：

1. 田二河讲述沈柳心兴办课堂式教育的遗训，揭示水围镇在灰土上坚持学校教育的由来与意义。
2. 田二河点明身旁三栋“品”字型楼正是旧水围镇学校，点题“曾经”，并自曝镇内新旧居民矛盾与自己死后镇子可能分裂的忧虑。
3. 蒋白棉向田二河打听黑发金眼男子，小狗子回报此人去了月鲁车站以北，且曾让整支狩猎小队莫名觉得有魅力想讨好他，本人却冷漠消失。

**逐章写法公式**：

- **情绪流向**：起：餐桌闲谈轻松 → 承：学校往事温情敬意 → 转：镇内矛盾与身后忧虑转沉 → 合：男子线索现身、雨夜悬疑
- **节奏配比**：慢铺垫 60% / 快冲突 15% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：由孩子上课引出教育话题（立水围镇“文明延续”形象）+ 揭示学校前身点题“曾经”（情感落点）+ 自曝镇内矛盾（交代隐患与镇长动机）+ 打听并获报神秘男子行踪（回收主线线索）+ 雨夜收尾（悬而未决）
- **本章核心技巧**：借一桌饭的闲谈把世界观、地点历史、势力矛盾与主线寻人线索逐层串起，以“今昔反差”制造情绪落点，全程无动作戏仍保持信息量推进
- **卡点与伏笔**：结尾卡点：信息悬念——目标男子现身月鲁车站以北且自带诡异群体魅力，下章期待追查其身份与异能；埋设伏笔：沈柳心的教育遗言与学校前身 → 点题并立住水围镇精神内核；镇内新旧居民矛盾与镇长身后之忧 → 为水围镇未来危机及依附公司埋线；金眼男子令人“忍不住想讨好”的异常 → 暗示觉醒者能力线索
