# 第21章 遭遇战

**概要**：黑沼铁蛇毙命后，龙悦红难以接受它在几秒内就被解决，蒋白棉补述自己在之前那次事故中失去的不仅是部分听力，还有整条左臂，并断言人类最强大的敌人永远是别的人类。话音未落她便察觉异常：一名穿戴军用外骨骼装置、挎「暴雨」冲锋枪的壮年男子端着轻机枪一马当先杀到，两辆重型摩托护住侧翼，黑色越野车殿后。这伙荒野强盗原以为遗迹猎人队伍与黑沼铁蛇两败俱伤，头目却从晶体护目镜里看到对方毫发无损、白晨的狙击枪正转过来。他靠综合预警系统侧跃避开第一枪，权衡逃跑会丢下阿禹、吉顺等全部同伴、且自己未必强过铁蛇，遂硬冲上去火力压制。蒋白棉抢占有三层鳞片的蛇尸作掩体，商见曜翻越车顶与龙悦红、白晨龟缩车头。强盗头目机枪子弹耗尽后换上榴弹发射器，为保住吉普车物资改瞄蒋白棉，借热能成像穿透冷却的蛇尸锁定她的位置，狞笑着开始选择榴弹弹道。

**关键事件**：
1. 蒋白棉揭示自己在事故中失去部分听力和整条左臂，并点出人类最强大的敌人永远是别的人类。
2. 荒野强盗团杀到，头目靠综合预警系统避开白晨的狙击第一枪，端轻机枪展开火力压制。
3. 四人依托蛇尸与车头各寻掩体僵持；头目换上榴弹发射器，借热能成像穿透蛇尸锁定蒋白棉，章末卡在选择弹道的瞬间。

**逐章写法公式**：
- **情绪流向**：起：战后余韵与诧异 → 承：强敌杀到、误判被真相打脸 → 转：机枪压制下各寻掩体的战术僵持 → 合：榴弹锁定、防护失效的生死卡点
- **节奏配比**：慢铺垫 25% / 快冲突 55% / 爽点爆发 5% / 悬念留白 15%
- **本章结构公式**：战果确认+主题点题（人类最危险为下一场战斗定性）+ 敌方视角登场（装备展示与误判）+ 第一枪规避（一击立起双方实力认知）+ 掩体选择与火力压制（战术细节撑满中段）+ 重武器锁定卡点（防护被热能成像破解）
- **本章核心技巧**：用敌我双视角切换制造信息差，让一场遭遇战同时承担主题兑现和下章危机两重功能
- **卡点与伏笔**：结尾卡点：危机型——榴弹发射器借热能成像锁定蒋白棉、弹道选择中，下章期待她如何脱身；埋设/回收伏笔：左臂伤残 → 本章揭示为生物义肢并埋下电能积蓄限制；黑沼铁蛇鳞片防弹 → 本章回收为掩体又在结尾被热能成像破解；人类最大的敌人是人类 → 本章即刻兑现为遭遇战
