# 第33章 第三十三章 第一个点

**概要**：吉普驶离水围镇时，镇内回荡着《静夜思》的朗读声，四人沉默良久。白晨坦言自己想成为公司正式成员，部分原因是那样能借阅很多书——旧世界废墟里的书籍早年被大势力搬走，剩下的多被当成柴火或被动物啃毁，危险废墟里或许还有但无人敢去。蒋白棉用玩笑活跃气氛后，引导组员复盘田镇长讲述的毁灭细节：「无心者」主要出现于大城市，乡村小镇的毁灭更像战争与地质灾变共同造成，她推测旧世界毁灭前可能已存在地质武器，有待探索废墟证实；又讨论遗迹猎人寻找的黑发金眼怪人，初见即令一群男男女女同时爱慕，蒋白棉将其归类为觉醒者，白晨猜测他在沼泽深处寻找什么。近中午，吉普抵达本次拉练第一个点——一座被多次搜刮过的钢铁厂废墟，蒋白棉布置两项任务：自行解决食物、绘制完整地图并标注关键点，随后她与白晨留守看车，让商见曜和龙悦红独自进厂历练。

**关键事件**：

1. 白晨透露入伙动机之一是能借书，并道出废墟书籍消亡史与父母留下的「老师」。
2. 小组复盘旧世界毁灭线索：「无心者」集中于大城市、地质武器猜想、无心者与战争因果存疑，被确立为旧调小组主要调查方向。
3. 黑发金眼怪人被蒋白棉归类为觉醒者，白晨推测沼泽深处藏有秘密，小组决定绕行并上报公司。
4. 抵达拉练第一个点钢铁厂废墟，蒋白棉下达找食与绘图两项任务，商见曜、龙悦红独自进厂。

**逐章写法公式**：

- **情绪流向**：起：驶离水围镇，朗读声中的怅然余韵 → 承：车内身世闲谈与互怼玩笑转暖 → 转：毁灭之谜与怪人讨论带出悬疑 → 合：抵达钢铁厂，任务下达、分组行动
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：驶离聆听朗读（收束上章余韵）+ 车内闲谈露身世（软化氛围、补人物）+ 组长引导复盘毁灭情报（确立调查方向）+ 抵达钢铁厂布置任务（开启拉练小目标）
- **本章核心技巧**：用行车对话把世界观信息分批抛出，再以最低难度任务收束并切出下一段独立行动
- **卡点与伏笔**：结尾卡点：任务型——两名新手独自进入钢铁厂，约定发信号求助、回两公里内用对讲机，下章期待两人首次独立探索的遭遇；埋设/回收伏笔：白晨「父母死后留下一个很好的老师」→ 人物身份悬念；地质武器猜想 → 旧调小组后续调查方向；黑发金眼觉醒者与沼泽深处秘密 → 荒野探索线；钢铁厂常有遗迹猎人出没 → 本章之后的潜在冲突来源
