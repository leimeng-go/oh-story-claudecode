# 第四十七章 寄于自然 摘要

**概要**：大沼泽各处接连响起苍凉嘶吼，古物学者杜衡听出月鲁车站以北的情况比预想更麻烦，决定连夜步行赶路。告别前他提起蒋白棉的名字让他想起故乡棉田，蒋白棉说出自己名字的由来——父亲是研究棉花改良的生物学家，她生于棉花丰收之月；杜衡则留下一句「我的年龄可比外表大多了」，道声「愿能再见」后走向北边黑暗荒野。留下的金发道士伽罗兰与旧调小组围篝火交谈，她自称灰土语学得好并非自愿，只因「道」的典籍都用灰土文书写；她吮着油手指大谈「随性可为、寄于自然」，讽刺最初城元老院的贵族当年连同伴的尿都抢着喝，如今却规定宴会一道菜一种餐具，蒋白棉由此推断她来自最初城。伽罗兰解释道士是信仰不同执岁的另一种僧侣，而她信仰的执岁正是「庄生」——即僧侣教团口中「世自在如来」在教外的名号，令知情的旧调小组成员暗自震动。她坦言在最初城加入「永恒岁月教派」，并以母亲去世不悲反笑阐述生死如四季轮回的教理，商见曜无法反驳。嘶吼声变调后伽罗兰也起身告辞，行礼念「至人无己，新世界就在眼前」后步行向北。蒋白棉调侃商见曜这次没跟着嘶吼「大合唱」，随后提醒众人今晚加强戒备、勿被宗教理论迷惑，并宣布将开始训练组员辨别可食植物、应急部位与代食泥土等野外觅食能力。一夜无事，天亮后吉普继续北上，蒋白棉开始介绍目的地：黑鼠镇的居民其实是一群次人。

**关键事件**：

1. 杜衡听出沼泽嘶吼的异常，判断事态麻烦，连夜独自步行赶往月鲁车站以北，临别暗示自己年龄远超外表。
2. 伽罗兰与旧调小组篝火夜谈，畅谈「寄于自然」的生存哲学并讽刺最初城贵族，蒋白棉推断她来自最初城。
3. 伽罗兰揭示自己信仰执岁「庄生」、隶属「永恒岁月教派」——「庄生」正是净法所说「世自在如来」在教外的名号，与第46章情报形成闭环。
4. 蒋白棉布置夜间戒备、宣布开展野外觅食训练，并警示地下宗教在灰土的隐患；次日清晨队伍出发，揭示黑鼠镇居民是次人。

**逐章写法公式**：

- **情绪流向**：起：嘶吼四起杜衡辞行（不安）→ 承：篝火夜谈嬉笑与机锋（轻松）→ 转：「庄生」二字砸落坐实教派关联（震动）→ 合：领队部署戒备与觅食训练，黑鼠镇次人信息收尾（期待）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：杜衡嗅险辞行（送走强援立危局）+ 伽罗兰夜谈露底（教派身份与哲学展示）+ 「庄生」名号坐实（回收净法情报）+ 蒋白棉队内部署（戒备、训练、宗教警示）+ 次人信息抛钩（引出黑鼠镇）
- **本章核心技巧**：用两场告别夹一场炉边闲谈，把情报揭示全部裹进闲聊口吻，靠名词落点与前文闪回完成认知爆破
- **卡点与伏笔**：结尾卡点：信息揭示型——「黑鼠镇的居民，其实，其实是一群次人」，下章期待次人聚落真容；埋设/回收伏笔：「庄生=世自在如来教外名号」回收（第46章净法情报→本章坐实）、杜衡「年龄比外表大得多」埋设（身份悬念）、永恒岁月教派与「至人无己」口号埋设（宗教线）
