# 第24章 信

**概要**：商见曜和龙悦红从被击毙的荒野强盗尸体上卸下军用外骨骼装置，龙悦红一边干活一边追问商见曜杀人时紧不紧张、心里难不难受，商见曜先答自己靠"目标是拯救全人类"压下恐惧，又说感受是"想再补两枪"，理由是对方先抱恶意一路追踪攻击，若自己犯一个错误，倒在这里被翻尸的就是自己，对方还会唱着歌吃他们的能量棒和军用罐头，龙悦红想起从小到大忍受的饥饿感勃然大怒，随即又蔫下去说不舒服，商见曜笑称"这就是灰土，好好习惯吧"。蒋白棉让龙悦红试穿缴获的外骨骼，电量剩23%、标称可用1小时55分钟，蒋白棉估算超负荷运转顶多撑半小时，并点明公司那台是仿制品、做生物的公司机械电子本就不强。商见曜搜遍尸体只找到两包红河文饼干、两张信纸和一枚徽章：整齐的信是死者儿子小安吉用灰土文写的家书，说自己在最初城正规学院求学、毕业即可摆脱奴隶身份成为公民，并提醒父亲今年冬天格外难熬要早备粮食、不要再做强盗；另一封皱信是猎人公会任务文书，悬赏一吨面粉、C级100信用积分，追查月鲁车站以北一名黑发金眼的风衣男。黄铜徽章正面人脸浮雕两颊刻刀枪、背面嵌芯片，证实死者是猎人公会遗迹猎人。

**关键事件**：

1. 龙悦红追问商见曜杀人感受，商见曜答"想再补两枪"，并用"对方先抱恶意、败者会被抢食侮辱"说服了龙悦红
2. 蒋白棉让龙悦红试穿缴获的军用外骨骼，实际高强度使用只能撑约半小时，小队获得战力升级
3. 尸体上搜出死者儿子小安吉的家书，揭示强盗同时是供儿子读书的父亲，并留下冬粮短缺的预警
4. 发现猎人公会任务文书与黄铜徽章，引出"月鲁车站以北、黑发金眼风衣男"的新线索

**逐章写法公式**：

- **情绪流向**：起：打扫战场的松弛插科打诨 → 承：关于杀人感受的道德追问与说服 → 转：家书揭示死者为人父，爽感转沉默 → 合：任务文书与徽章引出新悬念
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：拆卸外骨骼（收缴战利品收束上章战斗）+ 杀人感受对话（消化首次杀人的心理冲击）+ 试穿装备（战力升级小爽点）+ 读家书（情绪反转制造重量）+ 读任务文书看徽章（开新线索卡点）
- **本章核心技巧**：用翻检尸体物品的清单式流程，把搞笑对话、道德反思和新悬念三段不同情绪串在一条动作线上
- **卡点与伏笔**：结尾卡点：信息揭示型——黄铜徽章背面嵌芯片、确认为猎人公会徽章，下章期待小队是否追查黑发金眼风衣男、深入月鲁车站以北大沼泽；埋设/回收伏笔：小安吉家书中"今年冬天格外难熬" → 灰土冬荒危机伏笔；猎人公会C级任务文书与风衣男形象 → 新目标线索伏笔；商见曜"目标是拯救全人类"的口头禅 → 角色动机持续铺垫
