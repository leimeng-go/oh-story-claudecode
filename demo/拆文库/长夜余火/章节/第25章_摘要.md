# 第25章 第二十五章 打扫战场 摘要

**概要**：战斗结束后，蒋白棉用左手电鳗型生物义肢内置的感应装置读出死者猎人徽章的芯片，确认对方是一名"正式猎人"，并借此引出猎人公会的信用积分体系：积分满100才能从"新手猎人"升为"正式猎人"，其上还有中级、资深、高级、大师级，失信者会被标注甚至除名成为"黑暗猎人"。商见曜对义肢能读芯片感到好奇，蒋白棉解释读取容易、擦掉重写很难，芯片是公会从"机械天堂"统一购买的。两人随后意识到"在黑沼荒野搜集特定一人情报"的任务像往大海撒网抓特定一条鱼，猜测任务广撒给了众多猎人，悬赏总额远不止一吨面粉，蒋白棉对目标人物的来头生出疑问。白晨修好吉普但发现多处受损、随时可能抛锚且缺关键零件，提议绕道两三小时路程外的荒野流浪者聚居点交换零件，蒋白棉同意。众人清点战利品：一辆轻度受损的重型摩托、两把微型冲锋枪、一把"暴雨"冲锋枪、子弹和摩托零件，龙悦红还抱回一挺轻机枪，但因是7.92毫米口径暂时无法使用。蒋白棉安排外骨骼装置放副驾、众人轮流骑摩托，命大家捡回弹壳这一战略资源，并让龙悦红用外骨骼的高温切割功能剥下黑沼铁蛇的皮绑上车顶，蛇肉和毒囊则放弃。最后商见曜提议将三具尸体沉入沼泽，蒋白棉同意。

**关键事件**：

1. 蒋白棉用生物义肢读出徽章芯片，确认死者为"正式猎人"，并向商见曜解释读取原理。
2. 两人分析搜集情报任务的撒网式悬赏模式，对目标人物身份与悬赏规模生出疑问。
3. 白晨报告吉普多处受损、缺关键零件，提议绕道荒野流浪者聚居点交换物资，获蒋白棉同意。
4. 众人打扫战场：缴获摩托与枪械、剥下黑沼铁蛇皮绑上车顶，并将三具尸体沉入沼泽。

**逐章写法公式**：

- **情绪流向**：起：战后查验死者身份的平静 → 承：设定讲解与任务疑云带来的思索 → 转：吉普受损抛锚风险制造的紧迫 → 合：有序搜刮与沉尸收束的踏实
- **节奏配比**：慢铺垫 55% / 快冲突 10% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：读徽章确认死者身份（补全世界观）+ 对话拆解任务异常（埋幕后悬念）+ 吉普故障引出绕路计划（开启下章目的地）+ 清点处置战利品（收获爽感）+ 沉尸收尾（立角色准则）
- **本章核心技巧**：以"打扫战场"这一战后例行流程为骨架，把世界观设定、幕后悬念、下一站目标和物资收获逐一挂接到具体动作上完成多线输出
- **卡点与伏笔**：结尾卡点：行动收束型——尸体沉沼、车队即将绕道荒野流浪者聚居点，期待聚居点交易与吉普维修；埋设/回收伏笔：悬赏目标人物的身份与幕后势力 → 延续后续章节的追查主线；荒野流浪者聚居点 → 下章新场景入口；7.92毫米轻机枪暂无子弹 → 后续交易或火力储备素材；黑沼铁蛇皮 → "研究部"仿生盔甲线的回报钩子
