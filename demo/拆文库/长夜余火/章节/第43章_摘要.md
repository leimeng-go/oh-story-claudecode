# 第四十三章 “邀请” 摘要

**概要**：蒋白棉点破自己此前制定方案时连嗓音都不压低、关键时刻却不发声的矛盾，商见曜和白晨恍然大悟，两人各自把那份沉默理解成防范净法「他心通」的深谋远虑，蒋白棉笑称他们想得太复杂，并表态自己绝不会坑组员。她随后惋惜没能摧毁净法机体拿到仿生芯片，称僧侣教团多半了解旧世界毁灭原因、「永生人」是旧世界毁灭前最重要的项目之一，但随即自嘲真拿到了也不敢随身携带觉醒者的芯片。三人乘外骨骼装置循车痕追上一刻钟，看见龙悦红的吉普侧轮陷进淤泥，正被一男一女用灰色拼装越野车往外拖。对方瞥见军用外骨骼装置脸色突变翻滚躲避，商见曜当场卸甲示好才解除戒备。男子自称中级猎人吴守石，言谈间以坚持道德自傲，并透露月鲁车站以北发现了一座从未被发现过的旧世界城市废墟——有人进去后改了台无线电报机，把消息传回了野草城的公会。他把这定性为「危险和机遇」，说废墟物资足够成千上万个遗迹猎人团队分配、不必担心互相杀戮，向蒋白棉等人发出了共同探索的邀请。

**关键事件**：

1. 蒋白棉复盘「无声暗示」真相，商见曜、白晨才意识到自己把组长的沉默过度解读成防范他心通的安排。
2. 蒋白棉惋惜未能取得净法的仿生芯片，带出僧侣教团掌握旧世界毁灭线索、「永生人」项目的世界观情报，随即自我否定。
3. 龙悦红不熟路况把吉普开进淤泥，被路过的吴守石一行主动拖出，双方因军用外骨骼装置经历一轮戒备与示好。
4. 吴守石透露月鲁车站以北发现从未被发现过的旧世界城市废墟，情报经改装无线电报机传回野草城公会。
5. 吴守石以「危险和机遇、不必互相杀戮」为说辞，向旧调小组发出共同探索新废墟的邀请。

**逐章写法公式**：

- **情绪流向**：起：骗局复盘的轻松好笑 → 承：错过芯片的惋惜与自嘲 → 转：遭遇陌生人的戒备、卸甲后的缓和 → 合：新废墟情报与组队邀请带来的期待
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：复盘对话释疑（收束上章骗局、确立组内信任）+ 惋惜芯片带出设定（埋世界观伏笔）+ 载人循痕会合（动作过渡）+ 外骨骼惊吓与卸甲示好（低烈度小冲突）+ 吴守石抛出废墟情报（新主线信息投放）+ 发出共同探索邀请（结尾卡点）
- **本章核心技巧**：用一场低烈度公路邂逅完成「新地图开启」的信息投放，先以武力反差制造小悬念，再让陌生人口吻把下一段主线的利益与风险一次说透。
- **卡点与伏笔**：结尾卡点：悬念型——吴守石发出共同探索新城市废墟的邀请，主角团去留未定，下章期待小组的取舍与回应；埋设/回收伏笔：仿生芯片与「永生人」项目、僧侣教团掌握旧世界毁灭原因 → 埋设，长线世界观悬念；吴守石女伴颈部青黑色纹身与冰冷表情 → 埋设，身份暗示；月鲁车站以北新城市废墟 → 埋设，后续主线场景；蒋白棉「不管我做什么决定都要相信我不会坑你们」→ 回收并巩固，为小组内部信任定调。
