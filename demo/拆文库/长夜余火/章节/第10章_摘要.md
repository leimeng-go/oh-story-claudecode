# 第10章 “天选之子” 摘要

**概要**
商见曜对龙悦红的忐忑一言不发，两人乘电梯前往647楼报到，电梯里商见曜只说了一句“每个人都有自己的使命”，龙悦红则说出自己的愿望：留在公司内部娶妻生子、让孩子每周吃三顿肉，并得知商见曜是自己申请调入安全部的。抵达无铭牌的14号房间后，他们见到组长蒋白棉——一个身高近一米八、戴耳蜗、嗓门极大的D6级女子，以及矮小精悍、曾做过荒野流浪者的组员白晨。蒋白棉宣布小组全名“旧世界毁灭原因调查小组”，安全部和董事会还各有多支互不知情的旧调小组，原因是上一支人数众多的旧调小组外出调查时全员失踪、损失惨重，她随即说明小组将深入荒野废墟、面对各类敌人，连资深员工都不愿加入。被龙悦红追问时，她说出这个小组是自己申请成立的，梦想是查清旧世界毁灭原因、找到无心病根源与新世界大门；白晨为转正与基因改造资格主动加入，商见曜高喊“为了拯救全人类”，唯独龙悦红是今年毕业生里唯一未婚配、唯一被分来的人。蒋白棉温柔笑道：这样的人一般称为“天选之子”。

## 关键事件

1. 电梯中商见曜说“每个人都有自己的使命”，龙悦红袒露娶妻生子的朴素愿望，并得知商见曜是自己申请调入的。
2. 两人抵达647楼14号房间，见到戴耳蜗的大嗓门组长蒋白棉和荒野流浪者出身的组员白晨，旧调小组四人全员到齐。
3. 蒋白棉揭示小组真相：全名“旧世界毁灭原因调查小组”，因前身整组失踪才拆分为多支互不知情的微型小组，危险远超普通作战小组。
4. 四人说明各自加入缘由，龙悦红被确认是唯一被分配来的倒霉蛋，被蒋白棉冠以“天选之子”的称号收尾。

## 逐章写法公式

- **情绪流向**：起：报到路上的压抑忐忑 → 承：初见组长的错位轻松 → 转：任务真相揭开的恐惧下坠 → 合：反讽称号收束的苦笑
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：电梯对话交代心愿与主动申请（立住两人心态反差）+ 敲门入职、组长组员轮番登场（新团队亮相）+ 组长宣告小组真相与前身全灭旧闻（信息倾泻、情绪下坠）+ 逐个询问加入动机（群像立人、动机分野）+ “天选之子”反讽称号收尾（笑点卡点）
- **本章核心技巧**：入职报到场景用“信息逐层加码”推进——团队人数、小组性质、危险程度、个人命运一层比一层坏，靠沟通错位笑点防止压抑过载，结尾把坏消息反转为梗完成卡点。
- **卡点与伏笔**：结尾卡点：反讽称号型——“天选之子”命名龙悦红的倒霉体质，下章期待他的回应与小组待遇展开；埋设/回收伏笔：商见曜档案里的“那件事”与申请原因 → 被蒋白棉点破却不展开，留待后揭；旧调小组前身全员失踪 → 危险预期与长线悬念；城市废墟深处通向新世界的大门 → 长线目标与麦高芬；无心病根源 → 世界观级悬念。
