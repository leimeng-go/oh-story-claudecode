# 第18章 交易未成

**概要**：蒋白棉一行驾车行至软烂路段，前方开阔处停着一辆多次改装的烧油越野车和两辆重型摩托，五名武装男子拦路守候。蒋白棉让商见曜、龙悦红观察判断，二人分别指出对方"吃得挺好""装备不错"，白晨从车辆烧油推断对方熟悉这片区域，初步确认这是一支混得不错的遗迹猎人或荒野强盗队伍。蒋白棉命众人端起"狂战士"与榴弹枪亮明火力，并解释荒野上"尊重只在强者间"、展示肌肉才是友善的规则。双方接近至十米内互相对峙，为首的壮年男子高声回应不认识昨晚沼泽异常的来历，转而抛出诱饵：几个月前沼泽深处发现了一个从未被记录的城市废墟，他愿用大致位置换取食物，开价六十个军用罐头。蒋白棉本无诚意，直接回绝，双方和平错开。事后手下质疑为何不开枪，壮年男子以"受伤即成猎物"的猎人猎物哲学压下异议，年长者更从对方只有军用罐头、能量棒、压缩饼干推断他们刚从大势力出发、附近并无已知集镇。壮年男子最后点破：这片区域可供车辆通行的路线不多，对方很可能经过"那个地方"，于是带人上车悄悄尾随，打算等他们撞上那个大麻烦、拼到极限时再一网打尽。

**关键事件**：
1. 路遇五名武装男子（越野车+两辆重型摩托），蒋白棉借观察考校队员，确认对方是混得不错的遗迹猎人或强盗团。
2. 全队亮出"狂战士"突击步枪与榴弹枪，以"展示肌肉"的荒野规则震慑对方，蒋白棉给商见曜划定三种可开枪情形。
3. 壮年男子以"沼泽深处未被记录的城市废墟位置"为饵，开价六十个军用罐头，蒋白棉拒绝，交易未成，双方和平脱离。
4. 壮年男子压下手下开战主张，点破对方必经"那个地方"，率队尾随，准备等他们拼到极限后收网。

**逐章写法公式**：
- **情绪流向**：起：路遇武装小队、远近戒备 → 承：亮枪对峙、隔空喊话试探交易 → 转：拒绝成交、双方和平脱离 → 合：强盗复盘后决定尾随，杀机暗藏
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：观察判断对手（确立威胁等级）+ 亮枪立威并讲解规则（避免开战的实力展示）+ 喊话试探交易（抛出废墟线索又拒绝成交）+ 和平脱离（解除对峙）+ 反派复盘尾随（反转收束埋钩）
- **本章核心技巧**：一场没有打响的遭遇战，先写主角团的备战与试探，再切到对手视角复盘算计，用和平收束反衬尾随杀机。
- **卡点与伏笔**：结尾卡点：危机预告型——强盗团尾随在后，等主角一行撞上"那个地方的大麻烦"拼到极限再收网；下章期待：未知的大麻烦与前后夹击。埋设/回收伏笔：沼泽深处从未被记录的城市废墟及其与昨晚异常的关联 → 信息揭示，指向后续探索目标；"那个地方"发生的异变（大麻烦） → 悬念伏笔；黑色越野车后备箱里"那个东西" → 敌方底牌伏笔。
