# 第2章 复查 摘要

**概要**
统一婚配结果在老挂钟转了三圈半后终于显示在活动中心的液晶屏上，孟夏等人都找到了自己的名字，唯独龙悦红榜上无名；更让他震惊的是商见曜也没配对，因为商见曜已申请放弃本次统一婚配且公司特批不扣贡献点，这意味着男性只比女性多一人，龙悦红由此意识到自己才是几千人中唯一落单的倒霉蛋。随后显示屏公布配对者信息：孟夏的丈夫是被公司吸纳三年的荒野流浪者张磊，杨镇远的对象是比他大十岁、丧偶带娃且主动申请的周琪，周琪还亲自到活动中心把杨镇远领走。活动中心主管陈贤宇透露没分到对象的人岗位可能有危险，龙悦红哭丧着脸回家报信。商见曜则乘研究区电梯、用电子卡刷开权限按亮3楼，绕过有仿生盔甲安保把守的金属大门，到林医生处复查；林医生承认放弃婚配是她帮忙申请的，追问他坚持放弃的原因，商见曜正色回答是为了拯救全人类，而林医生面前文件上赫然写着中度精神异常（疑似妄想症，待观察）。

## 关键事件
1. 婚配结果公布，龙悦红发现自己榜上无名，商见曜自曝已申请放弃且公司特批不扣贡献点，龙悦红算出自己是几千人中唯一多出来的倒霉蛋。
2. 配对信息公示：孟夏的对象是荒野流浪者出身的D4员工张磊，杨镇远的对象是大他十岁、丧偶带娃的周琪，周琪亲自现身把杨镇远领回家。
3. 陈贤宇透露没对象、暂不用生育的人可能被分到危险岗位，龙悦红崩溃离场。
4. 商见曜凭电子卡权限进入研究区3楼找林医生复查，声称放弃婚配是为了拯救全人类，文件显示他被诊断为中度精神异常（疑似妄想症，待观察）。

## 逐章写法公式
- **情绪流向**：看榜期待 → 落单错愕与互相调侃 → 他人婚配众生相的啼笑 → 一纸诊断带来的寒意
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：看榜发现无名（制造落单悬念）+ 对话抖出商见曜弃配（扭转坏消息性质）+ 公示他人配对（侧写制度与世界观）+ 周琪领人、陈贤宇点破岗位规则（把笑点翻成危机）+ 商见曜独行复查、狂言与诊断对照（收束于身份悬念）
- **本章核心技巧**：全章用对话连锁反应推进信息释放，结尾用一行客观文字对前文所有怪诞言行重新定性
- **卡点与伏笔**：结尾卡点：定性型卡点，林医生文件写明中度精神异常（疑似妄想症，待观察），下章期待商见曜的异常真相与复查后续；埋设/回收伏笔：商见曜的电子卡能刷开研究区3楼权限 → 暗示其身份特殊，为后续特殊部门线铺垫；商见曜称放弃婚配是为了拯救全人类 → 悬置真实动机；陈贤宇的岗位分配说法 → 为下一章工作分配铺垫；龙悦红说商见曜脑子越来越不正常 → 本章即以诊断书回收
