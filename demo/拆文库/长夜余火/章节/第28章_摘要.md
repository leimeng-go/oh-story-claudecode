# 第28章 入镇

**概要**：白晨与水围镇镇长田二河继续交涉，得知镇上因田地有限已不再接纳外来流浪者，田二河自嘲心软爱帮人，还提到镇里靠旧世界废墟找回的《蘑菇种植与栽培技术》种出了蘑菇；白晨顺势许下将来卖高产粮种和补充肥力之物的口头承诺。随后白晨在镇里的零件仓库挑了几样配件，先以食物、燃油摩托报价被田二河压价，改报一挺用7.92毫米子弹的轻机枪后，田二河当即拍板成交，称这是守镇利器。成交后田二河以天要下雨为由，主动邀白晨带同伴进镇过夜且不必卸除武器。白晨返回向蒋白棉、商见曜、龙悦红如实汇报，蒋白棉先确认田二河七十七岁、亲历旧世界毁灭的身份可信，再向担忧遇劫的龙悦红分析：距冬天还有一个多月，对方不愿付出三五十条命的代价，且聚居点地形对人少精锐的一方反而有利。商见曜点醒龙悦红旧调小组的职责，众人才明白组长想从田镇长口中找旧世界毁灭的线索。全队赶在雨前入镇，被安置在围墙拐角的木棚，获赠炉子和木炭；蒋白棉拿出红烧牛肉罐头和叶子烟邀田二河共进晚餐，用旧世界故事换来一句成交，入夜时分全镇劳作的人陆续返回，好奇的目光纷纷投向吉普车停放的角落。

**关键事件**：

1. 白晨以摩托报价被压价后改提轻机枪，田二河当场拍板成交（零件换一挺7.92毫米口径轻机枪）。
2. 田二河以雨势将至为由，主动邀请白晨带同伴进镇过夜，破例不要求卸除武器。
3. 蒋白棉确认田二河亲历旧世界毁灭、身份可信，说服心存顾虑的龙悦红，全队决定入镇。
4. 蒋白棉以红烧牛肉罐头加叶子烟为代价，与田二河成交用旧世界故事换情报的晚饭之约。

**逐章写法公式**：

- **情绪流向**：起：闲话镇况的松弛 → 承：讨价还价的热络 → 转：去留之争的紧绷与说服 → 合：入镇受礼遇、以故事换情报的期待
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：白晨套近乎问镇况（建立人情与设定）+ 挑货议价连番报价（完成交易小目标）+ 镇长主动留客（抛出善意与疑点）+ 队内争辩定去留（确认信任与风险账）+ 入镇安置赠炉炭（兑现善意）+ 罐头叶烟约晚饭（开启情报交易钩子）
- **本章核心技巧**：用一桩具体交易嵌套入镇许可，再把入镇许可嵌套进旧世界情报目标，三层小目标逐层解锁推进剧情
- **卡点与伏笔**：结尾卡点：期待型+全镇目光聚焦吉普车角落，晚饭谈话未开始，下章期待田二河口中的旧世界故事；埋设/回收伏笔：《蘑菇种植与栽培技术》旧世界书籍 → 暗示废墟遗存有实际价值并呼应调查主线；白晨许下的高产粮种承诺 → 为后续长期交易关系留口；田二河亲历旧世界毁灭 → 下章回收为情报来源；轻机枪交换约定 → 待白晨一方兑现的交易尾巴
