# 第四十六章 不简单 摘要

**概要**：夜晚篝火旁，蒋白棉答应交流后，黑袍中年男子杜衡与金发女子伽罗兰毫不设防地坦然落座，这份底气让小队暗自警惕。杜衡自称历史研究员、古物学者，加入猎人公会二十多年最近才升正式，为探索新发现的旧世界城市废墟而来；伽罗兰自称道士，发表了一番"人法地，地法天，天法道，道法自然"的随遇而安之论。蒋白棉半透露身份以作威慑，又借"上天有好生之德"引出话题，透露小队刚与一名披红色袈裟的机械僧侣大战一场。杜衡透露红袈裟机械僧侣同时为觉醒者的概率不低，并分享觉醒者在心灵中探求新世界、僧侣教团称之为"极乐净土"的情报；伽罗兰进一步透露红袈裟僧侣有概率已进入"起源之海"，而进入之地公认称为"群星大厅"，商见曜听后眼眸微动。蒋白棉以两条烤兔后腿回报这些稀罕情报。随后杜衡断言新废墟绝对有异常：旧世界毁灭时周边小镇乡村有不少幸存者，却从未有人提过或探索过那座城市废墟，蒋白棉和白晨联想到水围镇田二河小小年纪都要回城寻父母，深表认同。话音刚落，北面远处传来一声粗哑苍凉的嘶吼，如噩梦降临。

**关键事件**：

1. 杜衡、伽罗兰加入篝火夜谈，双方互通身份，彼此判断对方"不简单"
2. 蒋白棉透露小队刚击败一名披红色袈裟的机械僧侣觉醒者
3. 杜衡、伽罗兰透露觉醒者体系情报："极乐净土""起源之海""群星大厅"
4. 杜衡断言新发现的城市废墟绝对有异常，话音未落北面传来诡异嘶吼

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：陌生人坦然落座引发警惕 → 承：互通身份、随遇而安论缓和氛围 → 转：觉醒者体系情报层层放出、废墟异常论敲定 → 合：嘶吼划破夜空，噩梦降临
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：落座试探（确立双方不简单）+ 自我介绍（立住两个新人物）+ 兔子之问（引出机械僧侣战绩）+ 情报换兔肉（释放觉醒者设定）+ 废墟异常论（回收旧伏笔锁定新目标）+ 嘶吼卡点（危险预告）
- **本章核心技巧**：整场戏由一个篝火夜谈场景承载，用"问答—请客—再问答"的交易节奏把设定倾泻伪装成闲聊，每放出一个名词就截断一次追问
- **卡点与伏笔**：结尾卡点：危险逼近型——北面传来粗哑苍凉嘶吼，下章期待怪物现身或夜袭；埋设/回收伏笔：群星大厅与商见曜的异常反应 → 暗示其觉醒者经历与该地相关；"起源之海"渡过之后抵达何处被刻意不答 → 后续设定钩子；水围镇田二河回城寻母旧细节 → 回收作为废墟异常的佐证
