# 第三十章 小小的“交易”

**概要**：田二河接着上章讲述灾变经历：市里到处是吃尸体的“无心者”，它们会攀爬幕墙、会使用枪支，同行八九人很快死了一半，他因年纪小个头矮才活下第一轮。众人躲进警察局找到枪弹，却因不会用枪反引来更多“无心者”，最后靠停车场一辆插着钥匙的越野车撞出市区。田二河此后再没见过父母。一行人返回水围镇，靠年货过冬，采纳“以劳动换食物”的提议，在春天前修好隔间、围墙、水渠、水塔并练熟枪械，后来这些都派上了用场；天气转暖后他们确认“救援永远不会来了”，转而探索周边城市废墟搜集物资。讲述间隙，商见曜和龙悦红去公共厕所，一路目睹聚居点的贫苦景象，体验了无格挡的简陋公厕，更加确认“盘古生物”地下大楼的美好。归途中，一个七八岁、衣着破烂的小女孩捧着线头、碎布、玻璃球等杂物，求换一点吃的。商见曜挑出内嵌黄色花瓣的玻璃球完成“交易”，把红烧牛肉撕成小块、提醒“小心烫”后喂给小女孩。蒋白棉叹气示意，远处十几二十个捧着杂物的小孩正眼巴巴围拢过来，商见曜身体僵硬；田二河起身吼退孩子们，孩子们一步三回头地散去。

**关键事件**：

1. 田二河讲述城市沦陷经过：“无心者”吃人、会用枪，同行者死伤过半，众人靠一辆无主越野车冲出市区。
2. 田二河交代水围镇幸存史：以劳动换食物、赶在冬天里完成基建，并最终确认“救援永远不会来了”。
3. 商见曜、龙悦红如厕途中见识地表聚居点的贫困与简陋公厕，对比出“盘古生物”的优越。
4. 商见曜用一块红烧牛肉换小女孩的玻璃球，引来十几个孩子围观，被田二河吼退。

**逐章写法公式**：

- **情绪流向**：起：围炉听末日往事的凝重 → 承：确认无救援的苍凉与镇上今昔对比 → 转：公厕插曲的窘迫笑料与小女孩乞食的温情 → 合：孩子群围拢被驱散的酸涩无力
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：田二河补述灾变史（交代世界观与水围镇来历）+ 两人如厕见闻（用日常切口展示聚居点贫困）+ 玻璃球换牛肉（以微缩“交易”呈现善意）+ 孩子群被吼退（温情撞破现实，留下两难）
- **本章核心技巧**：用“口述背景板 + 行进式白描见闻 + 微缩事件收尾”三层递进，把世界观信息全部落在人物当下的眼睛和动作上
- **卡点与伏笔**：结尾卡点：情境型——十几个孩子捧杂物围拢被吼退，善意无力为继，下章期待团队如何回应水围镇的贫困局面；埋设/回收伏笔：玻璃球（商见曜换得的“很好的东西”）→ 后续可作为商见曜性格与支线的记忆物件；“救援永远不会来了” → 回收旧世界毁灭设定，坐实新秩序背景；水围镇以劳动换食物的制度 → 为后续与其他聚居地对比提供参照
