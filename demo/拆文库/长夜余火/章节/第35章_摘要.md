# 第35章 怪异的死亡 摘要

**概要**：商见曜和龙悦红在钢铁厂废墟医院门口遭遇两名骑自行车的武装者，双方各自躲避举枪对峙。商见曜隔空喊话表明无恶意并提议交换情报，随后持枪先行走出掩体表诚意，对方派出三十来岁、秃头的红河人种中级猎人哈瑞斯·布朗接应。双方互通姓名后，哈瑞斯给出收费忠告：放弃寻找黑发金眼家伙的任务，月鲁车站以北最近很不太平。他证实沼泽嘶吼那晚自己就在北方，天亮后发现好几具刚死几小时的尸体，身上没有任何致命伤痕，表情却扭曲，有的痛苦，有的恐惧，有的似乎在笑，且衣物物品连头发都被先来者搜刮一空。商见曜以两小袋压缩饼干代替回答问题支付了忠告报酬，又得知附近还有几个遗迹猎人，装备够强便不会被招惹，而哈瑞斯对「没有武器」的假设答以「在灰土上，弱小就是原罪」。双方保持戒备拉开距离和平分别后，两人进入厂区，认出带沟槽的修理区，深入至烟囱附近阴森无声的钢铁支架区时，一具身体破损的人类尸体突然从高处坠落，紧接着拐角走出一个左臂架榴弹发射器、右掌带火焰喷口和激光发射孔的黑色金属骨架身影，套着破烂黄僧袍，披大红袈裟，双眼闪烁红光。

**关键事件**：

1. 商见曜与哈瑞斯·布朗一行在废墟门口对峙后和平接触，互通身份并交换情报。
2. 哈瑞斯证实月鲁车站以北出现怪异死亡：多具尸体无致命伤痕但表情扭曲，死者物品连头发都被搜刮一空，坐实沼泽嘶吼相关的异常。
3. 商见曜用两小袋压缩饼干支付忠告报酬，并得知附近尚有其他遗迹猎人，以及「弱小就是原罪」的灰土法则。
4. 两人深入厂区时一具尸体从高处坠落，身披僧袍袈裟的武装机械身影随即现身。

**逐章写法公式**：

- **情绪流向**：起：遭遇对峙的紧张戒备 → 承：情报交换中恐惧与跳脱笑点交替 → 转：残酷法则点出后和平分别，转入探索的压抑 → 合：坠尸与机械僧侣登场的恐怖爆点
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：遭遇对峙（建立戒备）+ 喊话换情报（推进信息）+ 忠告与怪异尸体情报（坐实异常威胁）+ 饼干支付和平分别（收束冲突）+ 入厂探索辨认布局（铺垫氛围）+ 坠尸与机械僧侣现身（卡点引爆）
- **本章核心技巧**：用一场和平的陌生人信息交换把前置悬念落地为具体威胁，再以立flag即兑现的坠尸卡点完成本章到下章的惊险跳跃
- **卡点与伏笔**：结尾卡点：危险登场型——身披僧袍袈裟、双眼红光的黑色金属武装机械体现身，其是否与坠尸及怪异死亡相关留待下章；埋设/回收伏笔：沼泽嘶吼与月鲁车站以北异常 → 本章借扭曲尸体情报回收坐实；高处坠尸与机械僧侣 → 新埋伏笔指向厂区深处威胁；寻找黑发金眼家伙的任务 → 延续线索，哈瑞斯放弃任务反衬其危险
