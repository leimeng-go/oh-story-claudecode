# 第45章 第三晚 摘要

**概要**

前往黑鼠镇途中，蒋白棉一行又遇几拨前往月鲁车站以北城市废墟的遗迹猎人，龙悦红不解为何有人纯靠步行，蒋白棉解释这是故意让前人踩雷的捡便宜策略，且废墟里废旧车辆零件遍地，步行者可就地"准备"交通工具，收获反而更多。因天色将晚赶不到黑鼠镇，众人在荒野小土包背风处扎营，蒋白棉借中午探索被净法打断、原任务无法完成为由"故意找事"，给商见曜和龙悦红换成天黑前完成一次狩猎的任务，验收地图时调侃商见曜标注了废弃厕所。两人找不到猎物，先想沿小溪找河捕鱼，又讨论能否用"推理小丑"骗猎物上门被否，转而向白晨请教猎兔技巧，结果花了一小时只灰头土脸提回一只野兔，自认太轻视兔子。烤兔时白晨撒盐香气四溢，蒋白棉却说缺油少香料只能"将就"，两人脱口而出"好奢侈啊"。就在此时蒋白棉察觉有两人靠近，全队戒备：来者是一男一女，黑袍长发中年男子与金发碧眼、灰蓝长袍缀满抽象符号的女子，女子以字正腔圆的灰土语行道礼"福生无量天尊"，男子自称闻着烤肉香来碰运气讨食，被拒后转而自夸学识渊博要求聊天，蒋白棉暗中示意众人保持戒备，笑着应下"好啊"。

**关键事件**

1. 蒋白棉向龙悦红解释步行遗迹猎人"让前人踩雷、废墟就地取车"的捡便宜逻辑。
2. 因赶不到黑鼠镇，队伍在荒野小土包扎营过夜。
3. 蒋白棉把商见曜、龙悦红被打断的原任务换成"天黑前完成一次狩猎"。
4. 两人请教白晨后耗时一小时仅猎回一只野兔。
5. 烤兔时两名身着长袍的陌生男女循香味靠近，女子用灰土语道"福生无量天尊"行礼。
6. 中年男子讨食被拒转而要求聊天，蒋白棉暗令戒备后应允，章节卡在对话将启处。

**逐章写法公式**

- **情绪流向**：起：赶路见闻引发好奇 → 承：扎营颁任务、狩猎小挫的轻松日常 → 转：烤肉将熟时陌生人靠近、全队戒备 → 合：神秘男女行礼求聊，对话未启即收
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：步行猎人疑问（植入废墟生存规则）+ 扎营换狩猎任务（给空闲时段立小目标）+ 请教与猎兔落空（制造落差完成经验积累）+ 烤兔评价对撞（用认知差写物资观）+ 长袍男女出现（以反常礼节立悬念卡点）
- **本章核心技巧**：用"小目标日常"填充赶路空白，在情绪最松弛处插入陌生人登场，把章节终点卡在新人物对话开启前一秒
- **卡点与伏笔**：结尾卡点：新人物登场型——长袍男女讨食被拒后转而求聊，蒋白棉应下"好啊"，下章期待两人的真实身份与来意；埋设/回收伏笔：女子灰蓝长袍上的抽象符号与"福生无量天尊"道礼（却用灰土语而非红河语）→ 指向其所属势力与教派身份；蒋白棉的隐蔽戒备手势 → 提示团队对来者的危险性预判；本章"狩猎别轻视兔子"的经验 → 小队野外生存能力的持续成长线
