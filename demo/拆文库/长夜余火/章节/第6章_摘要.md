# 第6章 夜遇

**概要**
商见曜再入"群星"大厅，越过反复宣告"一个代价，三个恩赐"的人型光影，来到尽头一扇嵌有三个凹槽的灰白石门前。他倾全身之力推门，凹槽内"星辰"亮起、虚幻文字翻滚不定，门却纹丝不动，直至力竭失败。他随后骈指抵住眉心，整个人变得"幽深"，再不发力地轻轻一按，三团文字终于固定为"推理小丑""矫情之人""双手动作缺失"，石门沉沉退开一线，露出其后向上的银白金属阶梯，但门缝只容手指和鼻尖挤过，他换尽姿势也无法通过，身影随即变淡消失。商见曜在495层B区196号房间醒来，听晚8点整点新闻广播：102层工厂火灾一死三伤、二号反应堆停堆维护致能源配给降低四分之一、员工因婚配结果互殴等，听着听着睡去，凌晨提前醒来，摸黑去公共厕所。归途他撞见深夜反向而行的邻居沈度，摸黑拍肩吓了对方一跳；沈度谎称去C区厕所找遗落物品，方向却明显背离最近的厕所。商见曜以"你穿绿大衣我也穿绿大衣"绕出"我们是教友"的结论，沈度恍然大悟，热情问他是否也去听"引导者"布道，商见曜笑着应下。

## 关键事件

1. 商见曜蛮力推灰白石门失败，改用两指抵眉心的方式后轻松按门，凹槽文字固定为"推理小丑""矫情之人""双手动作缺失"三个代价，石门退开一线。
2. 门缝后露出向上的银白金属阶梯，但商见曜只能挤过手指和鼻尖，无法进入，身影变淡、从大厅消失。
3. 商见曜在房间醒来，整点新闻广播交代公司内部状况：火灾死人、能源配给削减四分之一、因统一婚配引发的互殴。
4. 凌晨夜遇行踪反常的沈度，商见曜以"同款大衣"绕出"教友"身份，套出"引导者"布道一事。

## 逐章写法公式

- **情绪流向**：起：光影宣告规则，神秘感拉满 → 承：蛮力推门屡屡失败，憋屈累积 → 转：换法即通、门开一线却进不去，爽点被卡 → 合：回归日常后夜遇沈度，悬念重新点燃
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：光影复读规则（确立代价机制）+ 全力推门失败（垫高门槛）+ 抵眉心轻松按门（对比给出解法）+ 门开一线进不去（达成即降级）+ 醒来听新闻（场景落地并补世界观）+ 夜遇沈度套话（抛出布道新钩子）
- **本章核心技巧**：在目标达成的瞬间立刻降级成果（门开却进不去），随后用日常段落完成场景切换并顺势埋下一个新的人际悬念
- **卡点与伏笔**：结尾卡点：悬念型——沈度误认商见曜为"教友"，"引导者"布道是什么、沈度深夜究竟去干什么，留待下章一同去听布道揭晓；埋设/回收伏笔：三个代价"推理小丑""矫情之人""双手动作缺失" → 本章揭示名称，具体能力指向后续展开；"双手动作缺失"与推门必须用双手的反差 → 暗示代价与考验内容对应；整点新闻中的能源削减与统一婚配互殴 → 为公司内部矛盾铺垫
