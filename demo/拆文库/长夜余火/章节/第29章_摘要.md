# 第29章 第二十九章 回忆过去

**概要**：商见曜一行在水围镇广场休整，先观察到镇民衣着杂乱多补丁、浑身脏污，田二河主动解释：水源不缺但木炭要省，不许在附近砍树以防土地贫瘠，煤炭只能靠走私商队从"白骑士团"换，入秋后脏一点总比生病好，且镇民终日劳作无暇清洁；龙悦红联想到自己训练后筋疲力尽的经历表示理解。随后名叫"狗子"的镇卫队成员殷勤生火送炭，实则被干净漂亮的蒋白棉、白晨吸引。蒋白棉又拿出四个军用罐头，田二河让狗子取来自家铁锅与五副碗筷——淡青花纹的碗和象牙白的筷子比"盘古生物"员工家的还精致，田二河说这些取自旧世界城市废墟，遗迹猎人嫌占地方不愿背。蒋白棉趁机递上叶子烟，请田二河讲旧世界往事。田二河说这是他今年第二次抽烟，最大愿望是每年能抽三次，随后回忆：旧世界毁灭时他才十岁出头，寒假被父母送到水围镇旁的爷爷家，父母说好八天后来接，倒数第二天上午爆炸声与剧震接连不断，他一度昏迷，醒来发现爷爷家的房子塌了、爷爷奶奶没能逃出；幸存村民聚到镇上开阔地住帐篷等救援，通讯全断，救援始终没有来；他跟着几个大人离开水围镇回市里找父母，而市里"更加可怕"——话到此处戛然而止，田二河眼神失去焦距。

**关键事件**：

1. 田二河向商见曜等人解释水围镇镇民脏污的原因：木炭紧缺、禁伐树木、劳作疲惫。
2. 蒋白棉以军用罐头和叶子烟换取田二河信任，田二河借出锅碗并答应讲述旧世界往事。
3. 田二河回忆旧世界毁灭当天的经历：被送到爷爷家、爆炸与地震、爷爷奶奶遇难、镇上苦等救援无果。
4. 田二河讲到回市里找父母时说出"更加可怕"便陷入噩梦般的沉默，章节在此卡住。

**逐章写法公式**：

- **情绪流向**：起：观察镇民脏污、直评"不干净"的轻微尴尬 → 承：田二河解释缘由、狗子献殷勤、碗筷玩笑的轻松日常 → 转：叶子烟递上，话题切入旧世界，气氛转为凝重 → 合：童年灾难回忆倾泻，停在"更加可怕"的失焦沉默
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：观察镇民下结论（引出解释）+ 田二河拆解脏污成因（建立贫困设定与共情）+ 生火借锅碗的互动日常（松弛过渡、展示文明落差）+ 递烟换故事（小目标嵌套，打开回忆）+ 童年灾难倒叙（情感爆发）+ "更加可怕"戛然而止（留悬念）
- **本章核心技巧**：先用外部观察制造误判，再让知情者逐条拆解翻转读者认知，最后借一件小物件切换进第一人称创伤回忆并以断句留白收尾
- **卡点与伏笔**：结尾卡点：悬念型——田二河说市里"更加可怕"后失去焦距，下章期待市里惨状的具体内容与父母的下落；埋设/回收伏笔：伏笔"白骑士团煤炭很多"→ 暗示该势力富庶，为后续接触埋线；伏笔"每年能抽三次烟，这是今年第二次"→ 以烟标记田二河的创伤周期；伏笔旧世界废墟仍有大量物资无人取 → 为后续废墟探索铺垫
