# 第二十六章 “补课” 摘要

**概要**：战斗结束后，旧调小组把尸体抛进沼泽掩埋，蒋白棉抢先骑上缴获的重型摩托，第一次骑就沿沼泽边缘飞驰炫耀，结果不认识路又兜回来问白晨，还装作是自己的决定。队伍以低速在黑沼荒野穿行近两小时，蒋白棉屡次以侦察为名脱队兜风。接近聚居点后，白晨担心队伍的火力和车顶绑着的黑沼铁蛇外皮会引起荒野流浪者过激反应，提议自己先骑摩托去接洽，蒋白棉同意并递出头盔。等待期间蒋白棉借战利品卷烟引出战争创伤话题，表示香烟酒精管制药品都不是好办法，自己学过心理课程，队员精神紧绷随时可以找她聊；随后又开课补课，系统讲解灰土上危险的人类：穿外骨骼装置和仿生智能盔甲者、重武器团队、装生物义肢或做过机械电子改造者、僧侣教团僧侣、基因改良者（外界称天选者，只有公司和白骑士团能稳定出产原液）、比基因改良者更强但失败率死亡率极高的基因改造者、因污染畸变并与正常人类结怨成死敌的次人，最后揭示最危险的是能力诡异、无法人工制造、数量稀少的觉醒者，属保密知识，对付方法是拉开距离用枪远程解决，并告诫身体脆弱，大意时七八岁小孩也能干掉他们。章末白晨骑摩托沿软烂道路深入沼泽，前方路面出现一个轻轻晃动的红色光点，那是警告。

**关键事件**：

1. 蒋白棉第一次骑重型摩托兜风炫耀，迷路折返向白晨问路还装作是自己的决定。
2. 白晨提议独自骑摩托先去聚居点接洽，避免火力与黑沼铁蛇外皮刺激荒野流浪者。
3. 蒋白棉借战利品卷烟讲战争创伤，主动提供心理疏导渠道，并夸自己批准白晨入组眼光好。
4. 蒋白棉补课讲解危险人类分类，首次揭示觉醒者的存在、应对方法与保密要求。
5. 白晨深入沼泽，前方出现晃动的红色警告光点，接触结果悬置。

**逐章写法公式**：

- **情绪流向**：起：战场收尾的冷峻 → 承：摩托兜风与卷烟闲谈的轻松 → 转：危险人类课堂逐级加码的紧绷 → 合：红点警告的悬念收紧
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：战后收尸离场（翻页过渡）+ 摩托兜风笑料（卸压立人设）+ 白晨先行接洽（分线造悬念）+ 等待期补课讲课（设定批量投放）+ 红点警告卡点（切视角锁下章）
- **本章核心技巧**：用等待间隙的补课场景做设定倾倒，把世界观信息包装成师生问答与闲谈，结尾切到落单角色遭遇不明警告完成节奏翻转
- **卡点与伏笔**：结尾卡点：悬念型，白晨在沼泽深处遭遇晃动的红色警告光点，下章期待聚居点接触走向；埋设/回收伏笔：蒋白棉抚摸左臂感叹还是原装的好 → 暗示其左臂为生物义肢，呼应危险人类分类；觉醒者需保密且无法人工制造 → 为后续觉醒者登场埋点；红色光点 → 聚居点接触事件的引子
