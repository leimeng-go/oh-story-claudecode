# 第9章 岗位

**概要**：分配结果公布当天清晨，商见曜与龙悦红在员工食堂花8个贡献点吃过早饭，到活动中心等待岗位分配。闲聊中龙悦红提起母亲同事的女儿、广播站的冯云英，自惭条件一般没有部门预定，商见曜却认真追问对方住址门牌，扬言要直接去问她喜不喜欢龙悦红，吓得龙悦红岔开话题。被问想去哪个部门时，商见曜毫不犹豫答"安全部"——全公司死亡率最高、负责押送物资、与怪物和入侵者作战、探索旧世界遗迹的部门；新婚的杨镇远疲惫现身，坦言结婚很累但挺好，三人议论安全部虽每天一顿肉、升迁快至半年D4、退伍提一级，却少有人愿去，商见曜更表态"我想值外勤""为了拯救全人类"，呛得两人说不出话。董事会员工送来密封纸袋，陈贤宇逐名发信，龙悦红抽到"前往647层14号房间报到"——全楼650层中靠地的5层属安全部——当场脸如死灰；商见曜拆开同一报地址的信，笑着说是自己申请的。杨镇远分去36层研究所，大厅众人听闻商见曜进安全部，反觉自己的结果不算糟。龙悦红无法反抗——除非想全家被放逐——只得与商见曜走向通往最上五层的电梯，低声道："至少，能看见真正的天空。"

**关键事件**：
1. 商见曜当众宣称想进"安全部"、想值外勤，理由是"为了拯救全人类"，为分配结果埋下伏笔。
2. 分配信送达，龙悦红被分到647层即"安全部"，信纸落地、脸如死灰。
3. 商见曜亮出同一报到地址的信，并揭示"我是自己申请的"。
4. 杨镇远分到36层研究所，各人结果落定，两人动身前往最上五层报到。

**逐章写法公式**：
- **情绪流向**：起：等待分配的闲适闲聊 → 承：商见曜想去安全部的反常宣言制造不安 → 转：发信时刻龙悦红被判"死刑"、商见曜同去且自愿 → 合：接受命运走向电梯，以"能看见真正的天空"留一抹亮色
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：等待闲聊（铺垫分配悬念与世界观）+ 反常宣言（立主角人设与伏笔）+ 密封信发放（仪式化推高紧张）+ 拆信反应对比（绝望与自愿的错位爆点）+ 动身报到（收束并抛出新环境期待）
- **本章核心技巧**：用"先公布所有人的判决、最后才揭主角判决"的延迟揭示，把同一张分配信变成情绪反转装置。
- **卡点与伏笔**：结尾卡点：悬念型——两人走向通往最上五层的电梯，"至少能看见真正的天空"暗示将首次见到地表，下章期待安全部报到与新环境；埋设/回收伏笔：商见曜"为了拯救全人类"→本章回收为自愿申请安全部的动机伏笔（延续至后续）、冯云英→龙悦红情感线伏笔、647层14号房间→新场景锚点。
