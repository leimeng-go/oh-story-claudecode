# 第4章 流言 拆文摘要

**概要**：商见曜在活动中心拿着军用罐头追问陈贤宇"它会唱歌吗"，把老头问得怀疑耳朵。龙悦红拿着饭盒进来，商见曜问他是否请客被直接拒绝——商见曜靠父母抚恤和每月1200点大学生补贴勉强温饱。龙悦红分享喜事：父母要给他介绍没考上大学、刚参加工作的同事女儿认识，争取在明年统一婚配前自由恋爱，但随即自怜只有1米75、长相成绩都一般、没被部门预定。商见曜发现几米外围着一群人，两人凑过去，邻居任洁（战略委员会下属部门D3级员工）正在讲公司流言：公司可能要求想要孩子的夫妻上交生物材料，在研究区建"生育中心"，统一试管培养、人造子宫孕育，接回孩子时可能已好几岁，名义是把女性从怀孕生育中解放、缓解劳动力不足。围观者分成两派：年轻女性觉得是好事，任洁和一名男子则斥为将神圣权利交给机器，男子还提起旧世界因禁忌实验毁灭的传闻。任洁逼问商见曜和龙悦红立场，两人都附和"是啊"。有员工质疑只是流言、董事会下属机构的舅舅都没听说，任洁严肃要求大家届时若被征询意见一定反对；有人联想到会不会取消婚姻和统一婚配，知情者引董事会成员、副总裁季泽的话否定，称和谐健康的婚姻是维持员工精神状态稳定的关键。物资供应市场响铃提醒食堂开门只剩三分钟，众人起身。路上龙悦红指出商见曜竟然赞同任姨，商见曜让他换种说法再问，改问"生育中心制度怎么样"后商见曜答"这岂不是好事"，龙悦红无言以对。两人进入员工食堂，商见曜花14个贡献点打了红薯饭、烩白菜、杂粮馒头、水煮土豆，又到肉食窗花32点要了一份红烧肉（三块、多点汁，同街区阿姨说来得早才抢得到），刷电子卡后端清汤找到龙悦红。商见曜仔细规划吃法：先分出拌肉汁的饭，配肉刨饭，最后用烩白菜拌剩余肉汁饭一口气吃完，与龙悦红同时放下碗筷喊"满足"。饭后龙悦红约去活动中心，商见曜摇头说要回去听广播、早点休息。

**关键事件**：
1. 任洁向围聚员工散布公司流言：公司或建"生育中心"剥夺自然生育权，统一上交生物材料、人造子宫孕育。
2. 商见曜对同一议题两面作答——对任洁附和"是啊"，被龙悦红换成中性问法后答"这岂不是好事"，暴露其表态只看问法立场的特质。
3. 食堂晚饭戏：商见曜花46个贡献点（14点素菜+32点红烧肉）吃一顿奢侈晚餐，首次具体展开贡献点物价与物资配给生活。

**逐章写法公式**：
- **情绪流向**：日常闲聊（起）→ 流言冲击、阵营争论（承）→ 两面作答的反转笑点（转）→ 食堂吃肉的满足与平静收尾（合）
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：怪问开场（立人设勾好奇）+ 喜事闲聊（投放制度设定）+ 围听流言（核心冲突信息）+ 逼问表态（角色站队）+ 换问法再答（反转笑点立人设）+ 食堂打饭吃肉（物价设定+小爽点）+ 饭后归家（日常收束留余味）
- **本章核心技巧**：用一场食堂流言群戏同时完成世界观投放、配角群像与主角"见人说人话"特质的展示。
- **卡点与伏笔**：结尾卡点：日常留白型——商见曜拒绝去活动中心、要回去听广播早点休息，平静收束但暗示听广播是其固定重要事项；埋设/回收伏笔：生育中心流言 → 铺垫公司高层的生育/人口政策走向；季泽（季董）广播讲话 → 引出公司高层人物与广播媒介；"听广播"习惯 → 延续并强化主角与广播的关联；旧世界禁忌实验毁灭传闻 → 回收并加深旧世界毁灭之谜的世界观伏笔。
