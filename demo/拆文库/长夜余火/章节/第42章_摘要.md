# 第四十二章 “骗子” 摘要

**概要**：机械僧侣净法第一时间识破商见曜等人掩护吉普车逃离的意图，绕开外骨骼装置纠缠直追车痕，商见曜按最坏预案沿内线驱赶拖延。车痕连续拐弯迫使净法靠近内线寻找痕迹，商见曜抓住其变向间隙发射榴弹，被净法以反关节跳跃躲开。藏身树上的蒋白棉随即射出第二枚榴弹，净法喷出气体横移闪避但仍被冲击波震得失衡，双方距离缩至二十多米。净法发动「饿鬼道」让商见曜和白晨自认极度饥饿，白晨掏食物时从能源背包上滚落，商见曜却因事先含在口中未咽的压缩饼干争取到一两秒，边咀嚼边扣动扳机，电磁弹丸命中净法胸前打出凹陷裂痕。蒋白棉再掷出缠绕电弧的金属撑杆扎入凹陷，电流在净法体内绽放使其僵直，但净法靠应急后备系统重新启动，带伤狂奔逃离。蒋白棉确认净法被重创、修复前无法继续追踪，随后揭示月鲁车站会合方案是故意编造的假情报——她早怀疑净法监听系统极强，便连同伴一起瞒骗，完成连续拐弯后停车藏树设伏，由龙悦红继续开车在前方等候。

**关键事件**：

1. 净法第一时间识破拖延意图，绕开外骨骼装置直追吉普车痕，商见曜沿内线驱赶周旋，电量持续下降。
2. 商见曜借车痕拐弯逼净法靠近内线，发射榴弹逼出其反关节闪避，蒋白棉埋伏树上补射第二枚榴弹。
3. 净法发动「饿鬼道」，商见曜靠预含口中的压缩饼干抢出一两秒，电磁弹丸命中净法胸前造成明显损伤。
4. 蒋白棉掷出带电金属撑杆扎入凹陷使净法僵直，净法却靠应急后备系统重启，带伤逃离。
5. 蒋白棉揭示会合计划是骗局：她早已怀疑净法监听系统超强，故意瞒住所有人设下树上伏击。

**逐章写法公式**：

- **情绪流向**：起：意图被瞬间识破的被动压抑 → 承：消耗追逐中焦躁累积、两次榴弹伏击接连被躲 → 转：饿鬼道压制下饼干伏笔兑现、电磁命中加电杆钉地的连击爆发 → 合：敌人重启逃逸的失落与「全组被骗」的反转释然
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：净法识破意图被迫周旋（立困境）+ 车痕拐弯制造伏击窗口（造机会）+ 树上第二枚榴弹现身（藏兵揭示）+ 饿鬼道压制与饼干反制（危机中伏笔兑现）+ 电磁命中接电杆钉地（连击爆发）+ 净法重启逃逸（胜利打折）+ 骗局复盘（反转收束）
- **本章核心技巧**：先立一个「临场破绽」（饿鬼道诱敌进食），再用更早前埋下的「口腔藏饼干」细节兑现破局，最后以「连队友一起骗的假计划」完成二次反转。
- **卡点与伏笔**：结尾卡点：信息反转型——蒋白棉复盘监听疑点并坦白会合计划是骗局，下章期待净法受创后的后续与小组前往月鲁车站方向的新展开；埋设/回收伏笔：口中预藏压缩饼干 → 本章回收，饿鬼道下抢出射击窗口；净法监听系统超强的三处疑点（高炉感应女声、敢兜圈子消耗、首次袭击选副驾）→ 本章回收，构成骗局的推理依据；净法应急后备系统与冗余机体 → 埋设，受创逃逸留下后患；龙悦红驾车十分钟后等候 → 埋设，小组重新会合的去向。
