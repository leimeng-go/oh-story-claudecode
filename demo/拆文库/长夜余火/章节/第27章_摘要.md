# 第二十七章 水围镇

**概要**：白晨独自骑重型摩托抵达四水环绕、藏于大沼泽中的水围镇，在围墙外被守卫用激光瞄准警告。她摘下头盔展露女性身份以降低对方戒心，高喊求见镇长田二河。七十七岁的田二河登上墙头认出这位一年未至的故人，因喇叭没电让守卫代喊「白丫头，这一年死哪去了」，随即放行。白晨按规矩交出长短枪支与摩托进镇，说明来意是换汽车零件，田二河带她去挑选。途中田二河问起机器人35，白晨答「坏了」，老人沉默以对；他又自嘲越来越怕冷，儿女都已不在，不知能否熬过这个冬天，感叹新世界只有年轻人可以信，自己这种老家伙就算了。

**关键事件**：

1. 白晨抵达水围镇围墙外，被激光瞄准警告后展露女性身份求见镇长田二河，获准进镇但须交出全部武器与摩托。
2. 田二河与白晨久别重逢，确认她被某个团队收留，问及机器人35时得知其已损坏，沉默跳过话题。
3. 田二河带白晨去挑汽车零件，途中自述衰老怕冷、儿女皆亡，对新世界不抱期望，白晨劝慰「至少得看一眼新世界」。

**逐章写法公式**：

- **情绪流向**：起：围墙外被瞄准的戒备 → 承：镇长认出故人的轻松打趣 → 转：入镇后问及机器人35的沉默低落 → 合：老人自述将死、对新世界不抱希望的怅然
- **节奏配比**：慢铺垫 55% / 快冲突 15% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：抵达被拦（建立据点戒备与进入门槛）+ 展露身份求见（化解敌意并交代人物生存策略）+ 故人相认打趣（确认旧关系、放松氛围）+ 缴械入镇（立规矩、显信任）+ 闲谈揭旧伤（机器人35、儿女、衰老三层失落）+ 挑选零件途中收束于新世界话题（留下情绪余味）
- **本章核心技巧**：用一次交易拜访串起世界观说明与人物前史，把信息揭示全部藏在故人闲谈的停顿与岔题里
- **卡点与伏笔**：结尾卡点：情绪型+田二河感叹新世界只属于年轻人、白晨无言以对，下章期待交易过程与镇内更多人物互动；埋设/回收伏笔：机器人35「坏了」→ 暗示白晨过往经历留待后揭；田二河亡女楠楠与白晨年纪相仿 → 老人对白晨格外亲近的情感根源；田二河能否熬过冬天 → 小镇支线的生死悬念
