# 第5章 “群星” 摘要

**概要**：龙悦红欲劝说商见曜，最终只说了一句“也好”作罢。商见曜交还餐盘后离开“物资供应市场”，穿过生活区C区与涂鸦街道进入B区，用黄铜钥匙打开属于自己的495层B区196号房间。这是一个两米宽、三米深、四米高的狭小房间，带独立洗手台和灶台，在楼层众多、能源与下水系统分片供给的地下大楼里已属难得。商见曜为省能源配额不开灯，靠墙半躺，目光落在锈迹斑斑的电炒锅与电饭锅上：一个是父亲参加“安全部”对外行动从旧世界遗迹带回的战利品，一个是母亲攒贡献点换来的。他记起自己原本的家在本层A区28号，父亲失踪、母亲死后房子被公司收回，如今这套是他考入大学离开孤儿院时新分配的；窗边的木桌是父亲亲手所做，母亲缝的衣物经孤儿院托管三年后归还，却再也穿不下。商见曜闭眼捏了捏太阳穴，静默如沉睡。随后他睁眼，发现自己置身一个比“物资供应市场”还大的空旷大厅，黑色墙壁上方昏暗之中密布缓缓转动的璀璨光点，如群星河流——他只在大学显示屏上见过一次星空。大厅中央星光凝聚成一道保持天平姿势的模糊人影，空洞的声音回荡着“群星”的启示：“一个代价，三个恩赐。”

**关键事件**：
1. 商见曜回到B区196号房间，通过房间陈设与旧物交代其父母失踪、死亡及房屋被收回的身世背景。
2. 商见曜不开灯、靠墙静坐，闭眼捏太阳穴后进入神秘的群星大厅。
3. 星光凝聚成天平姿势的人影，传达启示“一个代价，三个恩赐”。

**逐章写法公式**：
- **情绪流向**：平静日常 → 旧物勾出身世隐痛 → 闭眼静默 → 梦境降临、悬念陡起
- **节奏配比**：慢铺垫 70% / 快冲突 0% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：归家动作（收束上章对话）+ 房间白描（立世界观）+ 旧物溯源（交代身世）+ 静坐入梦（转场）+ 人影启示（卡点）
- **本章核心技巧**：以居室与旧物的静态白描承载人物前史，再用一次静默动作完成现实到神秘空间的硬切。
- **卡点与伏笔**：结尾卡点：悬念型——天平人影宣告“一个代价，三个恩赐”，下章期待揭示代价与恩赐的具体内容；埋设/回收伏笔：群星大厅与天平人影 → 开启超自然主线；父亲参加“安全部”对外行动后失踪 → 身世追查线；本章无回收。
