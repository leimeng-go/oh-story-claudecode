# 第16章 插曲

**概要**：旧调小组在大沼泽边缘的废墟旁宿营热罐头时，蒋白棉察觉有东西靠近却不慌不忙，安慰受惊的龙悦红说商见曜在戒备、天没塌就不影响填饱肚子。罐头热好之际，一名衣衫褴褛、指甲尖长的雌性"无心者"从建筑顶部扑向龙悦红，被蒋白棉用"联合202"手枪一枪击穿胸肩毙命。蒋白棉判断其为发病不超一年的初代，并讲述无心者（失心者、兽化病、返祖病）的设定：旧世界毁灭时大量人类失去理智只剩本能，至今无药可防，是笼罩人类的阴影。商见曜却指出这不是他先前看见的黑影——那个更矮一点，暗示附近还有别的存在。蒋白棉吩咐两人搜尸、发对讲机（有效范围两公里），商见曜答非所问说"我会修"。两人抬尸到火光边缘挖坑掩埋，龙悦红被恶臭熏得险些呕吐、食欲大减。入夜后大沼泽各处突然响起此起彼伏的野兽嘶吼，蒋白棉判断深处可能出了事但与路线无交集，主张绕开不管，并借两种表述教龙悦红"学会抓事情的本质"。商见曜全程镇定，自称只是在考虑要不要参与，随即张口学着发出一声"嗷呜"。

**关键事件**：
1. 无心者夜袭：雌性无心者扑向龙悦红，蒋白棉抬手一枪击毙
2. 无心者设定揭示：无心病=兽化病，发病机理不明、无法预防，至今威胁人类
3. 商见曜的警告：被击毙的不是他看到的黑影，"那个黑影要更矮一点"
4. 沼泽群兽嘶吼：异常声响四起，小组判断与路线无交集决定绕行
5. 商见曜学狼嚎回应"要不要参与"，制造反差笑点与疑点

**逐章写法公式**：
- **情绪流向**：起：宿营松弛、新人警觉 → 承：无心者突袭、一枪毙命 → 转：设定揭示+"不是那个黑影"的二次悬念 → 合：群兽嘶吼决定绕行，商见曜学嚎收在怪诞笑点
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：动静预警（立新人胆怯与组长松弛）+ 罐头香气（把松弛推到顶点蓄势）+ 突袭秒杀（爽点+立实力）+ 尸体讲课（落地世界观）+ 黑影否认（埋新危机）+ 搜尸埋尸（发对讲机道具）+ 夜吼议事（确立荒野生存逻辑）+ 学嚎收尾（人物怪癖+卡点）
- **本章核心技巧**：把一场小型遭遇战当作挂载点，前半用感官细节蓄势、中段秒杀释压，随后密集插入世界观说明与二次悬念，全程用"新人慌、老人稳"的反应对照推动信息释放
- **卡点与伏笔**：结尾卡点：人物反差+悬念——商见曜学狼嚎回应"要不要参与"，下章期待他口中的"更矮黑影"与沼泽异动揭晓；埋设/回收伏笔：更矮的第二个黑影 → 本章埋设，指向附近未知存在；大沼泽深处的异常事件 → 本章埋设，指向后续路线；对讲机（有效两公里） → 本章埋设道具，为分队通讯做准备；无心病随机发病 → 本章埋设世界观级威胁
