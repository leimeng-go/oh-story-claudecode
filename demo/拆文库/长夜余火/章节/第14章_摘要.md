# 第14章 黑沼荒野

**概要**：吉普驶出银白色大门，商见曜和龙悦红第一次见到真正的天空与太阳，龙悦红直视太阳看得流泪，蒋白棉递来墨镜，商见曜抢先戴上，白晨又递出一副花很多东西从女性遗迹猎人处换来的玫红墨镜。两人发现地表并非教科书渲染的昏暗灰蒙，白晨补充说仍维持恶劣状态的地方意味着污染、疾病和畸变。途中蒋白棉恶作剧降下车窗，商见曜一本正经评价外面"有新鲜的屎味"；白晨问出蒋白棉生于新历23年、比自己小三岁却已D6，蒋白棉笑称安全部升职快是因为上司随时会死，又状似随口提到自己"之前还做过一些贡献"，并提醒观察空气颜色、必要时提前戴防毒面具。进入黑沼荒野边缘后，龙悦红察觉环境不对，商见曜点破"没有人"，蒋白棉解释附近的人要么被公司吸纳要么流浪去有食物的地方，白晨低声说进入黑沼荒野后遇到的人类"未必是你们想要的"。龙悦红想起没告诉家人要外出拉练，蒋白棉说上面会派人通知。过了边缘哨所，地势平坦、泥土灰黑、树木扭曲，白晨讲授沼泽行车要领，蒋白棉在一处地下河出水口停车休息补水，教两人观察植物畸变和水生物异常、用生物清洁片净水，随后责骂龙悦红光顾着看新鲜忘了拔"冰苔"戒备，而商见曜早已持枪警戒，并突然报告：那边有人影闪过。

**关键事件**：
1. 商见曜、龙悦红第一次出地表，直视太阳、戴墨镜、发现真实环境与教科书描述完全不同
2. 年龄揭示：蒋白棉仅比组员大两岁已D6，并留下"之前做过一些贡献"的欲言又止
3. 商见曜点破荒野"没有人"的异常，白晨暗示黑沼荒野里遇到的人未必是好事
4. 河边休整教学净水与戒备，结尾商见曜发现人影闪过，遭遇战一触即发

**逐章写法公式**：
- **情绪流向**：起：初见地表的震撼与狂喜 → 承：闲聊打趣中的信息与人物揭示 → 转："没有人"的异常与白晨的低语让气氛下沉 → 合：河边教学后一句"有人影闪过"收紧
- **节奏配比**：慢铺垫 55% / 快冲突 10% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：初见太阳（建立新奇感）+ 抢墨镜打趣（调节节奏、立人物关系）+ 年龄与履历对话（埋人物伏笔）+ 无人异常点破（扭转氛围）+ 河边生存教学（展示世界观细则）+ 人影卡点（开启下章冲突）
- **本章核心技巧**：用旅途闲聊承载世界观与人物信息，在松弛段落里分散埋雷，结尾一句异常报告瞬间收束张力
- **卡点与伏笔**：结尾卡点：悬念型——商见曜报告河边"源头"位置有人影闪过，下章期待遭遇对象与冲突；埋设/回收伏笔：蒋白棉"之前做过一些贡献"欲言又止 → 人物履历悬念；观察空气颜色、提前戴防毒面具 → 后续遭遇污染/毒气场景的工具；白晨"未必是你们想要的"低语 → 黑沼荒野人类威胁预告；防毒面具、"冰苔"、生物清洁片 → 生存物资清单持续回收
