# 第三十六章 僧侣

**概要**：商见曜和龙悦红认出对面高大机器人是僧侣教团的机械僧侣"永生人"，本章借"盘古生物"教材交代其来历：旧世界"意识上传"科技可将人类意识传至机器人仿生芯片实现永生，大灾变后自称永生人的机器人现身，因技术不成熟，不少永生人失去肉体感受后精神失常伤害人类，剩余者从旧世界宗教残籍拼凑出自洽却扭曲的新宗教，自称僧侣，据点称琉璃净土。机械僧侣不怕轻武器、火力强大，通常友善却为维持种群四处强渡"有缘人"，且多有触发型精神失控，灰土视之为洪水猛兽。两人举枪自知毫无胜算，只能祈祷不是有缘人。僧侣无视他们，先对摔死的尸体念"众生皆苦"，随即出声叫住正后撤的两人，称二人与佛无缘但不妨听经；两人暗喜止步。僧侣以掌心炽白净火焚尸超度，自称法号净法，令两人坐下，开讲菩提是十三位执岁之一、一月主宰、万物的起始、意识的萌芽和化身。

**关键事件**：

1. 商见曜和龙悦红认出对面的机器人是危险的机械僧侣"永生人"，举枪戒备但自知无胜算
2. 教材式背景揭示：意识上传技术、永生人的失控史、僧侣教团与琉璃净土的由来
3. 两人后撤时被僧侣出声叫住，获知"与我佛无缘"后暗喜止步听经
4. 机械僧侣净法以掌心净火焚尸超度，盘腿坐下向两人传教，抛出菩提为十三位执岁之一的设定

**逐章写法公式**：

- **情绪流向**：起：突遇机械僧侣、认出危险 → 承：教材插叙永生人来历与失控史 → 转：后撤被叫住、获"无缘"放行却被迫听经 → 合：净法焚尸传教，抛出执岁设定
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：遭遇辨认（确立危险等级）+ 背景插叙（解释恐惧从何而来）+ 后撤被留（冲突再度压紧）+ 无缘放行（张力松绑却不放人）+ 焚尸示范（武力威慑定型）+ 坐下传教（引出世界观钩子）
- **本章核心技巧**：用角色当下的生理恐惧反应引出整段世界观插叙，再回到现场以"对方无攻击意图但自己无法反抗"的僵局完成压迫式收尾
- **卡点与伏笔**：结尾卡点：信息揭示型——菩提为十三执岁之一、一月主宰、意识的萌芽和化身，下章期待传教内容与两人如何脱身；埋设伏笔：机械僧侣触发型精神缺陷 → 后续失控风险；"有缘人"强制渡化 → 僧侣教团主线冲突；琉璃净土 → 后续据点与意识上传设备线索
