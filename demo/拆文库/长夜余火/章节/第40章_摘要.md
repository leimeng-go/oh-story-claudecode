# 第40章 第四十章 追赶 摘要

**概要**：脱离净法控制后，蒋白棉一边驾车避开沼泽与障碍、一边感应周围电信号提防机械僧侣追来，途中与众人复盘刚才的战斗：她自述被能力命中时记得往事却无法确认自己是谁，检讨误判了影响净法身体能否封锁其能力；商见曜指出觉醒者能力更依赖意识，剧痛或打晕都能令其用不出能力，并透露一名觉醒者正常只有三种能力。众人据此拼出净法的底牌——扰乱自我认知、「饿鬼道」、「他心通」，并由他远扑时只选「饿鬼道」推断其有效范围至少二十米，而扰乱认知的能力或范围更小、或只能针对单人。龙悦红此时才真正消化好友商见曜是觉醒者的事实，蒋白棉主动提出为商见曜保密，众人应允。净法的榴弹与激光随即袭来，蒋白棉急转躲避，白晨以「十一点」时钟方位指引可行驶方向；商见曜穿戴军用外骨骼装置跳车反扑，净法却不接战，转身兜圈拉开距离后甩掉追踪。商见曜破坏车辙、伪造痕迹后归队，指出「他在躲着我」。此后净法间隔不定地袭扰多次，碰面即退，蒋白棉推断他带了高性能电池，想把外骨骼装置耗到没电，而白晨发现净法最近几次只用激光武器——榴弹或已所剩无几，龙悦红忧问「那我们该怎么办」，车队陷入被拖入消耗战的僵局。

**关键事件**：

1. 蒋白棉复盘被净法能力命中的状态：记忆未失却无法确认「自己是谁、要做什么」，并检讨影响净法身体未能封锁其觉醒者能力。
2. 商见曜揭示觉醒者能力更依赖意识、正常一名觉醒者只有三种能力，众人由此锁定净法三种能力：扰乱自我认知、「饿鬼道」、「他心通」。
3. 由净法远扑时只用「饿鬼道」，推断其有效范围至少二十米，扰乱认知能力或范围更小或仅限单体，为后续对战提供依据。
4. 龙悦红确认商见曜觉醒者身份，蒋白棉带头承诺保密。
5. 净法以榴弹、激光远程追击，商见曜穿军用外骨骼跳车反扑，净法避战兜圈甩脱追踪。
6. 净法转为间歇袭扰、碰面即退，蒋白棉识破其意图是耗光外骨骼装置电源，白晨发现其弹药似将耗尽只用激光，车队陷入消耗战僵局。

**逐章写法公式**：

- **情绪流向**：起：劫后驾车的紧绷提防 → 承：复盘对话中拆解敌人能力、消化队友秘密 → 转：榴弹激光突袭，反扑却被避战甩脱 → 合：识破消耗战意图，弹药将尽却无从下手
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：行车复盘（把上一章战斗经验换算成敌人能力参数）+ 秘密收束（队友反应与保密约定稳固团队）+ 突袭反扑（展示外骨骼战力却被避战）+ 意图揭示（敌人避战的真实目的曝光，留下消耗战难题）
- **本章核心技巧**：用车内复盘对话把上一场战斗重新加工成敌人能力数据库，再以敌人反常避战的行为把战斗悬念从「打不过」切换成「打不着」
- **卡点与伏笔**：结尾卡点：难题型——净法意图耗光外骨骼电源且似乎榴弹将尽只用激光，龙悦红问「那我们该怎么办」，下章期待车队破解消耗战的对策；埋设/回收伏笔：「饿鬼道」有效范围至少二十米、扰乱认知能力或单体或小范围 → 为后续对净法作战提供距离依据；商见曜想到剧痛、打晕可封锁觉醒者能力「这也能用来对付自己」 → 埋下商见曜自身弱点伏笔；「永生人」意识脱离仿生芯片能维持多久清醒 → 埋下净法机体弱点伏笔；蒋白棉未展开讲述净法杀害女性的惨状 → 维持净法威胁的恐怖感留待后文
