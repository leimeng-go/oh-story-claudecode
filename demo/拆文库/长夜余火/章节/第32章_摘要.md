# 第三十二章 复盘

**概要**：雨夜的水围镇，蒋白棉宣布野外拉练第一堂课：四人各自以自身为主角复盘白天与外骨骼强盗的战斗。白晨、商见曜、龙悦红、蒋白棉依次讲完后，蒋白棉点评商见曜主动出击射杀两名摩托车手果断但鲁莽，能活下来很大程度靠运气。龙悦红追问若敌人不犯错该如何应对，蒋白棉直接否定：人少无重武器时对付不了军用级外骨骼装置，机会只在对方穿戴前动手或抢在拉近前驾车赛跑；当时地形异变加黑沼铁蛇大战已令小队近乎绝境，全靠敌人舍不得能源和战利品、计算太清楚才活下来。她透露自己原本备有诈降近身反扑和设陷阱射要害两个方案，陷阱却还没想好。白晨补充荒野思路：强盗多为劫财，可弃车引开、躲入外骨骼无法行走的沼泽。次日白晨修好吉普，田二河接收轻机枪和摩托车并添赠一顶帐篷，看到车顶黑沼铁蛇外皮后与镇民震惊沉默。田二河带蒋白棉、商见曜参观镇子，教室里十岁左右的孩子在破衣寒晨中端坐上课。吉普驶离时，楼内传出孩子们齐诵《静夜思》的稚嫩声音。

**关键事件**：

1. 蒋白棉组织四人雨夜复盘白天战斗，逐一以自身为主角陈述经历。
2. 蒋白棉定性商见曜射杀摩托车手果断但鲁莽，活下来靠运气。
3. 蒋白棉揭示军用级外骨骼敌人不犯错时小队无解，并给出穿戴前动手、驾车赛跑两种应对时机。
4. 蒋白棉透露自己原有诈降反扑与陷阱射要害两个方案，陷阱尚未想好。
5. 白晨提出弃车引开强盗、躲入外骨骼无法通行的沼泽的荒野方案。
6. 田二河验收修好的吉普、接收武器并添赠帐篷，被车顶黑沼铁蛇皮震惊。
7. 蒋白棉、商见曜随田二河参观水围镇教室，离开时听见孩子齐诵《静夜思》。

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：雨夜隔绝的安静中开复盘课 → 承：逐人陈述加逐条拆解险境 → 转：「还没想好」拆台与白晨荒野方案带来的松弛 → 合：次日参观教室，离别时书声余韵收束
- **节奏配比**：慢铺垫 30% / 快冲突 0% / 爽点爆发 0% / 悬念留白 10% / 对话推进与温情收束 60%
- **本章结构公式**：蒋白棉发起复盘（把上一场战斗信息补全）+ 点评商见曜（修正读者对胜利的认知）+ 拆解外骨骼威胁（建立装备体系敬畏）+ 揭底两方案（组长形象祛魅）+ 白晨补方案（视角差异教学）+ 修车交割物资（收束交易线）+ 参观教室与听诵诗（水围镇人情线落点）
- **本章核心技巧**：用战后复盘把已结束的战斗重新讲一遍，借角色之口逐条否定读者先前建立的胜负认知，再以温情场景完成情绪转换。
- **卡点与伏笔**：结尾卡点：余韵型——吉普驶离时孩子齐诵《静夜思》，下章期待小队继续上路与水围镇后会有期；埋设/回收伏笔：军用级外骨骼装置的弱点（穿戴前、速度、续航）→ 后续遭遇同类敌人的应对依据；白晨的荒野求生思路（弃车入沼泽）→ 铺垫她的流浪者经验价值；田二河「希望能够再见」与水围镇课堂 → 水围镇人情线伏笔，留待回访回收；蒋白棉的「反扑手段」与未想好的陷阱 → 她隐藏实力的悬念延续。
