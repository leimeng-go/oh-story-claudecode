# 第13章 仪式感

**概要**
高强度训练两个月后，蒋白棉突然宣布今天开始野外拉练：借上面派的小任务，给三百多公里外祈丰镇的流浪者聚居点送净水装置过滤芯片。白晨用地图讲明黑沼荒野没有好路，中途隔着盘踞怪物群和旧世界废墟的大沼泽，排除公司设哨所的常用路线后只剩两条需一到两周的路线。商见曜以"线条流畅，形状优美"选路，蒋白棉竟赞同拍板，只给15分钟准备。换装时商见曜戴上"盘古生物"铭牌，蒋白棉以灰土强盗根本不在意大势力为由要求出公司就摘，他大声回答"仪式感"。四人通过650层层层虹膜门禁，在地表区停车场领齐全套武器和不足全程的补给，驱车穿过近二十名守卫把守的最后一道大门，出生以来第一次上地表的商见曜和龙悦红被染着金色的刺眼阳光照得抬手遮挡。

## 关键事件

1. 蒋白棉无征兆宣布野外拉练，借送净水装置过滤芯片的任务当天出发前往祈丰镇。
2. 白晨讲解黑沼荒野与大沼泽的路线情报，商见曜以"线条流畅，形状优美"选定路线，蒋白棉附和定案。
3. 商见曜戴"盘古生物"铭牌被要求出公司后摘掉，蒋白棉讲明灰土上大势力的名头没有威慑力。
4. 四人领取全套武器装备，驾车穿过最后一道大门，出生以来第一次踏上地表。

## 逐章写法公式

- **情绪流向**：起：训练成果的自得与插科打诨 → 承：突袭宣布拉练、路线情报带来的紧张与好笑 → 转：铭牌插曲点题，温馨幽默下透出灰土规则的冷 → 合：冲出大门被第一次见到的阳光刺痛
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：电梯秀训练成果（确认两个月成长）+ 组长突袭宣布野外拉练（启动外出主线）+ 地图讲解与荒谬选路（释放世界观信息兼造笑点）+ 限时换装与铭牌对话（点题并立灰土规则）+ 领武器过门禁出发（仪式感逐级抬升）+ 大门开启金光刺眼（感官卡点收束）
- **本章核心技巧**：把外出任务的全部世界观信息嵌进"宣布—讲解—准备—出发"的行动流程里，用笑点和仪式动作消解紧张，最后以身体反应引爆"第一次上地表"的情绪。
- **卡点与伏笔**：结尾卡点：感官悬念+新地图开启——最后一道大门敞开，染着金色的刺眼阳光照入，两人抬手遮挡，期待下章地表真容与旅途开端；埋设/回收伏笔："盘古生物"铭牌 → 本章点题"仪式感"并引出灰土规则；净水装置过滤芯片与祈丰镇聚居点 → 后续章节任务线伏笔；黑沼荒野四方势力（救世军、白骑士团、最初城） → 世界观格局伏笔；补给支撑不到祈丰镇需野外获取 → 后续生存训练伏笔。
