# 第8章 圣餐

**概要**：任洁结束以育儿知识为内容的布道后，主持圣餐礼，给教众分发黑芝麻糊，新人商见曜排在最后却分到几乎填满小碗的一大勺，吃完还刮净碗壁。李姓女子问感想，他答"很好吃"，建议"圣餐再多点""要提前刷牙"，随后被单独留下听任洁讲解教义：教团最重视婴儿诞生与死者离去，仪式在新生命满月或下葬时举行，十二月首日迎司命、末日愿主打开新世界大门，行礼方式分"终将归于司命""赞美您的宽容""新生如日/生命最重"三类；圣餐每次不同但都是流食——流食正是新生命和将逝者的主要食物。商见曜追问执岁数量，得知执岁共十三位而非十二位，多出一位代表闰月的执岁，任洁却不知其尊称。回家后商见曜认真刷牙，进入群星大厅默数"银河"，数到十三后沉默消失。次日天亮，他前往C区物资供应市场，路上遇提前等他的龙悦红，对方因今日出分配结果而紧张，商见曜看到哄婴儿的女子后表情迷茫，说自己在"怀疑人生"。

**关键事件**：
1. 任洁主持圣餐礼，分发黑芝麻糊，商见曜作为新人分到最后却分量极多
2. 李姓女子询问感想，商见曜答"很好吃""圣餐再多点""要提前刷牙"
3. 任洁单独讲解教团教义与礼仪，揭示圣餐皆为流食的原因
4. 商见曜追问执岁数量，得知执岁共十三位而非十二位
5. 商见曜在群星大厅数出十三条"银河"，与执岁十三位形成对应
