| 项目 | 内容 |
|------|------|
| 标题 | 统一分配下的反常者 |
| 类型 | 主线 |
| 概要 | 新历46年，地下大楼"公司"以统一婚配和统一分配岗位维系人口与秩序。商见曜在统一婚配日陪好友龙悦红等待结果，平静宣称自己已申请放弃婚配——这是无人敢违反的公司核心义务。结果揭晓，龙悦红成为几千人中唯一落单者，而商见曜的放弃竟获公司特批、不扣贡献点。群像配角各自领走命运：孟夏配给荒野流浪者出身的张磊，杨镇远被大他十岁的周琪当场领走。随后商见曜凭电子卡进入研究区3楼复查，病历档案揭晓其父亲商世安随"旧调小组"整组失踪、母亲病逝、他为查真相主动参加C-14机密实验且"实验失败"、被诊断为中度精神异常。傍晚的集市与食堂日常中，生育中心流言、红烧肉物价与"它会唱歌吗"的怪问继续加厚公司世界与主角的反常人设。 |
| 核心目标 | 让读者在四章内建立"公司制度世界 + 商见曜是规则外的变量"的双重认知 |
| 核心冲突 | 个人（商见曜/龙悦红）vs 公司制度（强制婚配、岗位判决、处罚阶梯） |
| 关键信息功能 | 让读者获得公司阶级/贡献点/婚配制度的完整秩序图景；误判商见曜只是"怪人"，再在章尾被病历定性为"病人"；期待岗位分配结果 |
| 读者需求 | 认知惊喜（陌生制度的解谜快感）+ 代入感（相亲/分配的普世焦虑）+ 期待感（主角凭什么豁免） |
