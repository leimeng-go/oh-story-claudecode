# 情绪模块：长夜余火（第1-23章节选）

> 权威范围：读者需求 / 情绪引擎 / 套路框架运转 / 可复现模块。禁止把原文具体桥段当模板照搬。

## 读者需求 / 情绪引擎

| 读者需求 | 本书满足方式 | 证据章节/情节点 | 持续追读机制 | 可迁移边界 |
|---|---|---|---|---|
| 认知惊喜（解谜快感） | 世界观分层释放：制度层（婚配/贡献点）→ 宗教层（执岁/司命）→ 行动层（旧调任务），每层只揭一半 | 第1章P3-P7；第7章P15-P18；第10章P14-P17 | 每次释放都伴生更大的未知（代价名称有了，能力是什么？） | 保留"半真半假分层释放"；必须替换神明体系、制度细节 |
| 优越感/信息差 | 读者持续领先书中人物：先知道商见曜弃配（龙悦红不知）、先看到病历、先拼出能力 | 第2章P5-P7；第22章P15 | 信息差对象轮换（龙悦红→小组成员→敌人） | 保留"读者拼图领先"结构；替换被蒙在鼓里的角色 |
| 情感补偿（小人物被善待） | 残酷世界里持续投放温情：红烧肉、玫红墨镜、"比如，白晨"、罐头壳给男孩 | 第4章P20；第14章P4；第15章P14；第17章P14 | 每次残酷揭示（储备粮/捕奴队）后必跟一个暖意画面 | 保留"寒意+暖意双轨"；替换物件与人物 |
| 安全感（团队羁绊） | 四人小组各有缺陷但互补：组长稳、白晨老练、商见曜异常、龙悦红正常人 | 第10-13章群像；第21-23章战斗配合 | 战斗配合逐场升级（提醒戒备→火力交叉→三线夹击） | 保留"缺陷互补型小队"；替换成员缺陷与分工 |
| 期待感（能力/身世之谜） | 主角的异常严格"展示效果不点名"：病历→大厅→代价名称→能力初显 | 第2章P23；第6章P6；第22章P15；第23章P2 | 每4-6章投放一块拼图，书中只有白晨起疑 | 保留"多视角碎片拼图"；替换能力类型与代价 |
| 荒诞幽默（娱乐性） | 商见曜语录体系：错位回答贯穿所有场景，紧张场景也不例外 | 第1章P13；第13章P10；第16章P19 | 语录与场景反差越大越好笑（选路线/学狼嚎/请战） | 保留"错位逻辑自洽"的人设笑点；替换语录素材 |

## 故事框架与套路运行图

| 框架/套路 | 在本书中的位置 | 运行方式 | 为什么有效 | 失效风险 |
|---|---|---|---|---|
| 规则怪谈（信息差） | 第1-9章公司制度线 | 制度规则借剧情内文本（条目/档案/密封信）投放 → 主角成为规则例外 → 例外原因成谜 | 规则越具体，例外的信息量越大 | 规则写成说明文就死；例外给太早解释就泄压 |
| 机缘逆天（变体） | 第5-6章群星大厅 | 金手指以"代价"命名交付 → 门只开一线 → 能力展示先于命名 | 反升级流：先立规矩再谈开挂，期待期拉长 | 代价与恩赐长期不兑现会疲劳 |
| 扮猪吃虎（变体） | 第12章藏拙、第22-23章能力初显 | 不用主角视角扮猪，用敌人和队友的误判视角 | 读者拼图领先，爽感来自"我知道他不知道" | 误判方太蠢会显得刻意 |
| 绝境翻盘 | 第19-23章遭遇战 | 火力失效 → 底牌（义肢）→ 新绝境（外骨骼）→ 心理破绽翻盘 | 两次翻盘用不同机制（装备底牌/能力暗示），不重复 | 连续绝境靠运气翻盘会崩信用，本书用伏笔（金属杆）前置化解 |
| 以小搏大 | 第21-23章 | 四人无重武器 vs 军用外骨骼 | 地形（蛇尸掩体）+战术（车底射击）+异常（能力）三层补齐实力差 | 没有伏笔的以弱胜强是开挂；本书每层都有前文铺垫 |

## 可复现模块卡

### EM-001 反常者人设

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一个在所有场合都"不对劲"但自洽的主角，永远猜不到他下一句说什么 |
| 情绪链 | 缺口（这人怎么这样？）→ 加压（庄重/危险场景）→ 触发（错位语录或行为）→ 爆发（笑点或反转）→ 余波（其他角色被呛/无言） |
| 戏剧单元 | 庄重或高压场合中，主角用逻辑自洽但完全错位的回应打破场面的预期走向 |
| 关键触发物 | 误判者（以为他正常的角色）、见证者（负责被呛的反应位）、庄重场景 |
| 复现步骤 | 1. 先立一个"错位但自洽"的思维模式 2. 放进最不适合它的场合 3. 让配角替读者吐槽 4. 关键时刻让错位变成伏笔（症状即能力） |
| 可替换项 | 错位类型（语录/行为/决策）、场合、吐槽担当、伏笔指向 |
| 不可照搬 | 商见曜的具体语录、"为了拯救全人类"口号、思维跳跃=能力的具体设定 |
| 关联节奏 | TR-001, TR-004, TR-005 |

### EM-002 命运判决书

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 小人物被庞大制度裁决时的窒息感，以及裁决结果的超预期反转 |
| 情绪链 | 缺口（判决将至，人人自危）→ 加压（规则细节与处罚阶梯先行展示）→ 触发（仪式化判决动作：看榜/密封信）→ 爆发（最坏结果落地+同伴信息反转）→ 余波（黑色幽默或新恐惧） |
| 戏剧单元 | 制度以仪式化流程公布对个体的裁决，个体无力反抗，信息在最后时刻反转情绪性质 |
| 关键触发物 | 误判者（自认倒霉的人）、仪式物件（显示屏/密封信）、反转信息（同伴的秘密） |
| 复现步骤 | 1. 先用旁观群像把制度压力铺满 2. 仪式化动作逐级抬升紧张 3. 让最坏结果先砸在一个人身上 4. 用另一个人的信息把它撞碎重组 |
| 可替换项 | 判决类型（婚配/岗位/抽签/审判）、仪式物件、反转信息内容 |
| 不可照搬 | 统一婚配制度细节、647层="安全部"的具体设定、"天选之子"称号 |
| 关联节奏 | RH-001, RH-003, TR-001, TR-005 |

### EM-003 底牌藏到出手一刻

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 绝境中翻盘的爽感，且翻盘依据必须早已埋在读者眼皮底下 |
| 情绪链 | 缺口（解法预期全部落空）→ 加压（逐个否定常规方案）→ 触发（反常指令/动作）→ 爆发（底牌亮相一击定局）→ 余波（玩笑式揭晓+限制说明防开挂预期） |
| 戏剧单元 | 绝境中指挥者发出当时无法理解的指令，执行瞬间才揭示其依据——该依据在前文以"反常细节"形态出现过 |
| 关键触发物 | 前置的反常细节（金属杆/不带帐篷）、被否决的常规方案、出手后的限制声明 |
| 复现步骤 | 1. 至少提前3章埋一个"不合理的行李/习惯" 2. 绝境处先让读者和角色一起否定所有明牌 3. 指令先行、解释后补 4. 揭晓后立即给出使用限制 |
| 可替换项 | 底牌载体（义肢/道具/能力）、绝境类型、限制条件 |
| 不可照搬 | 电鳗型生物义肢、金属杆导电的具体设计、"你们值得拥有"台词 |
| 关联节奏 | RH-005, TR-009 |

### EM-004 敌方视角误判打脸

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 自以为是的猎手发现自己才是猎物的那一刻 |
| 情绪链 | 缺口（敌方登场亮实力）→ 加压（敌方基于错误信息的完美算计）→ 触发（敌方视角亲眼看到真相）→ 爆发（误判逐条被打脸）→ 余波（敌方被迫改变打法，局势反而更危险） |
| 戏剧单元 | 用一段纯敌方视角展示其信心与依据，再让现实逐条证伪，打脸瞬间同时抬升双方的危险等级 |
| 关键触发物 | 误判依据（两败俱伤的预期）、真相揭示媒介（护目镜/目击）、被打脸后的应激升级 |
| 复现步骤 | 1. 先让主角团真实付出过代价（可信度） 2. 敌方基于过时信息制定计划 3. 真相用敌方感官（而非叙述者）呈现 4. 打脸后敌方升级而非崩溃，维持威胁 |
| 可替换项 | 误判内容、揭示媒介、敌方升级方式 |
| 不可照搬 | 外骨骼护目镜视角、"就是现在，冲"、黑沼铁蛇两败俱伤的具体情境 |
| 关联节奏 | RH-005, RH-006, TR-010 |

### EM-005 小物件的温情接力

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 残酷世界里，被大人物忽略的小东西如何成为另一个人的希望 |
| 情绪链 | 缺口（世界很冷，读者需要暖）→ 加压（强者一方的"无用"决定）→ 触发（物件被弱者一方捡起）→ 爆发（物件在弱者生活中的全部重量被展示）→ 余波（一句台词把暖意拧成心酸） |
| 戏剧单元 | 主角团丢弃/留下的一个小物件，镜头跟随它转移到世界底层的角色手中，揭示其截然不同的价值 |
| 关键触发物 | 被弃物件、捡拾者、底层角色的分配计划、收尾的一句台词 |
| 复现步骤 | 1. 让强者给出"反常的放弃"（先压住真实原因） 2. 镜头跟物件转移到新角色 3. 用分配/使用细节展示物件的重量 4. 一句日常台词完成情绪反转 |
| 可替换项 | 物件类型、捡拾者身份、分配计划、收尾台词 |
| 不可照搬 | 罐头壳→小七→拾荒男孩的具体链条、"冬天过去，妈妈和爸爸是不是就回来了"原句 |
| 关联节奏 | TR-008 |

### EM-006 剧情内文本投放设定

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 高密度世界观，但不想读设定说明文 |
| 情绪链 | 缺口（对世界好奇）→ 加压（一个必须使用文档的场景）→ 触发（角色朗读/翻阅/收听）→ 爆发（文本内容改变对前文的理解）→ 余波（文本没说的部分成为新谜） |
| 戏剧单元 | 设定信息全部经由"世界内部存在的文本"（档案/广播/布道/显示屏条目/密封信）释放，叙述者不直接讲解 |
| 关键触发物 | 文本载体、使用场景、文本的"言外之意"（没写的比写了的重要） |
| 复现步骤 | 1. 为每类设定发明一个世界内部的文本载体 2. 给角色一个非读不可的理由 3. 文本只写"该载体真会写的"内容 4. 用载体的局限性制造新悬念 |
| 可替换项 | 载体类型（病历/新闻/教义/公告/信件）、使用场景、留白位置 |
| 不可照搬 | C-14病历格式、生命祭礼教义细节、"整点新闻"的具体条目 |
| 关联节奏 | TR-002, TR-003；全书各章 |

## 重组与复现指南

1. 先选读者需求，再选模块卡，不要从原文桥段倒抄。
2. 保留情绪链和功能位，替换人物、场景、动机、道具、事件素材。
3. 复现到新书大纲时，至少改变：冲突对象、公开/私密场景、触发证据、余波方向中的三项。
4. 若人设与模块冲突，以人设驱动重构模块；不要为了套套路扭曲角色。
