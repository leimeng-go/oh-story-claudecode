| 概要 | 深夜，商见曜在狭小房间里闭眼捏住太阳穴，坠入一座群星密布的大厅，天平姿势的模糊人影宣告"一个代价，三个恩赐"。再入大厅，他蛮力推三凹槽石门失败，改用骈指抵住眉心的方式后轻松按开一线——凹槽文字固定为"推理小丑""矫情之人""双手动作缺失"三个代价，门后露出向上的银白阶梯，门缝却只容手指鼻尖通过。现实中，他凌晨撞见行踪反常的邻居沈度，用"同款绿大衣"的歪理套出"教友"身份，混入秘密宗教聚会。引导者竟是白天散布流言的任洁：教团"生命祭礼"信仰执岁中掌管十二月的司命，宣称以祭礼托付可入新世界得永生，庄严布道的内容却是全套育儿经。圣餐礼上，商见曜得知执岁共十三位而非十二位；回家入大厅默数"银河"，数到十三后沉默消失。次日他看到哄婴儿的女子，对龙悦红说自己在"怀疑人生"。 |
| 核心目标 | 建立全书超自然主线的两套规则装置：群星大厅（代价/恩赐）与灰土宗教生态（执岁/司命） |
| 核心冲突 | 商见曜 vs 群星大厅的考验（代价支付与"进不去的门"）；个人信仰 vs 公司禁令 |
| 关键信息功能 | 让读者获得代价三名称、执岁十三位两个硬设定；误判"实验失败"与"精神异常"的性质——大厅的存在暗示一切另有真相；期待代价对应的能力揭晓 |
| 读者需求 | 认知惊喜（神明体系解谜）+ 期待感（金手指规则成形）+ 荒诞幽默的娱乐补偿 |
