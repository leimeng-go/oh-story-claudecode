## 故事框架

| 项目 | 内容 |
|------|------|
| 框架类型 | 混合（谜团驱动 + 成长冒险 + 群像日常） |
| 核心驱动 | 旧世界为什么毁灭——主角团以"旧世界毁灭原因调查小组"身份踏入灰土，逐层揭开世界真相；内层引擎是商见曜"一个代价，三个恩赐"的异常之谜 |
| 主轴矛盾 | 人类苟安于地下秩序 vs 灰土之上的未知真相与生存威胁（无心病、怪物、同类） |
| 升级机制 | 双线递进：明线是公司职级（D1→D2…）与装备获取（武器课→外骨骼战利品）；暗线是群星大厅的代价/恩赐能力体系（三个代价已命名，门只开一线） |

| 预期剧情数 | 23章线性节选，按每4-6章一个剧情单元预期4-5个，实际5个，通过 |

## 故事线一：旧世界毁灭之谜（主线）

| 项目 | 内容 |
|------|------|
| 标题 | 旧世界毁灭之谜 |
| 类型 | 谜团线 |
| 描述 | 阶段1（第1-4章）：世界以"公司"形态呈现——统一婚配、贡献点、楼层阶级，旧世界只在遗物与流言中投下影子（禁忌实验毁灭传闻）。阶段2（第5-8章）：超自然维度打开，执岁神明体系与生命祭礼教团表明"旧世界毁灭"在宗教叙事里有另一套解释，任洁称毁灭"只是正常发展的必然"。阶段3（第9-13章）：主线正式立项——蒋白棉的旧调小组以前身全灭为代价存在，目标三连：查清毁灭原因、找到无心病根源、找到传闻中城市废墟深处的"新世界大门"。阶段4（第14-23章）：小组踏入灰土，强盗口中"沼泽深处从未被记录的城市废墟"成为第一个具体线索，与"那个地方的大麻烦"一并指向后续探索。整条线以"信息分层释放"运转：制度层（公司知道多少）→ 宗教层（教团相信什么）→ 行动层（小组去验证什么）。 |
| 情绪引擎摘要 | 以世界观缺口（为什么毁灭/新世界是否存在）制造持续好奇，每次释放半真半假的一层（流言→教团教义→小组任务），详情见 EM-006 |
| 套路运行方式 | 规则怪谈式解谜嵌进废土冒险框架：设定不以说明文给出，全走档案、布道、广播、强盗喊话等剧情内文本，见 EM-002 |
| 主题 | 真相与秩序、文明的代价 |
| 包含剧情 | 统一分配下的反常者、群星启示与生命祭礼、旧调小组集结、尾随杀机与遭遇战 |
| 模块引用 | EM-002, EM-006 |

## 故事线二：商见曜的异常与群星启示

| 项目 | 内容 |
|------|------|
| 标题 | 商见曜的异常与群星启示 |
| 类型 | 谜团线 |
| 描述 | 阶段1（第1-2章）：以喜剧形态出现——错位语录、敢放弃婚配、公司特批，章尾被病历定性"中度精神异常（疑似妄想症）"。阶段2（第3章）：档案揭出因果链——父亲随旧调小组失踪→主动参加C-14实验求力量→"实验失败"→思维跳跃后遗症。阶段3（第5-6章）：群星大厅开启，"一个代价，三个恩赐"与三个代价名称（推理小丑、矫情之人、双手动作缺失）落地，门只开一线。阶段4（第8章）：十三条银河对应十三执岁，"怀疑人生"暗示大厅与现实神明体系存在映射。阶段5（第16-23章）：异常开始外溢到现实——察觉强盗攻击欲望、"不是那个黑影"、敌人十米之内"忘记扣扳机"、头目"不！我就不！"情绪劫持、垂死扣不动扳机，而商见曜只说"稍微有点头疼"。整条线严格执行"展示效果、不点名原理"的延迟揭示：读者在23章末已能拼出"疑似影响他人情绪/思维的能力+代价是思维跳跃"，但书中人物只有白晨起疑。与故事线一在"C-14实验""旧调小组"两个节点深度交织。 |
| 情绪引擎摘要 | 缺口=主角身上到底发生了什么；持续以"受害者视角呈现能力效果"（忘扣扳机/情绪上脑）替代能力解说，详情见 EM-003 |
| 套路运行方式 | 反转打脸的变体：不是主角亮实力打脸，而是敌人被看不见的力量"打脸"，爽感来自读者拼图领先于书中人物，见 EM-003/EM-004 |
| 主题 | 疯狂与天赋的一体两面、代价与救赎 |
| 包含剧情 | 统一分配下的反常者、群星启示与生命祭礼、尾随杀机与遭遇战 |
| 模块引用 | EM-001, EM-003 |

## 故事线三：灰土众生相

| 项目 | 内容 |
|------|------|
| 标题 | 灰土众生相 |
| 类型 | 其他（世界观支线/群像） |
| 描述 | 阶段1（第2-4章）：公司内的众生——张磊（荒野流浪者出身的D4）、周琪（主动再婚配的丧偶女性）、任洁（流言传播者/秘密引导者）、李祯（失育丧子的教徒）。阶段2（第6-8章）：信仰层生态——生命祭礼的教众都是"从未见过天空"的公司员工，教义把生育与死亡仪式化。阶段3（第14-17章）：荒野层生态——储备粮强盗团、最初城捕奴队、聚居点流浪者，以及全书第一个情感重锚：独眼机器人小七与拾荒男孩相依为命，"冬天过去，妈妈和爸爸是不是就回来了"。阶段4（第18-23章）：强盗团的人性切面——老大的猎人哲学、阿禹吉顺的内讧溃逃与"我他妈也是胆小鬼"。这条线不参与主线解谜，功能是让世界"有人"：每个阶层都有自己的生存逻辑与尊严。与主线在"城市废墟线索""那个地方的异常"处交汇。 |
| 情绪引擎摘要 | 以"淡说重事"制造寒意（储备粮/捕奴队）、以小物件接力制造暖意（罐头壳→男孩），悲喜双轨供给情感补偿，详情见 EM-005 |
| 套路运行方式 | 不套爽文套路，用纪录片式群像支撑主线世界的可信度，是慢热文的情绪压舱石 |
| 主题 | 生存、废墟上的尊严 |
| 包含剧情 | 统一分配下的反常者、群星启示与生命祭礼、初上地表与荒野法则、尾随杀机与遭遇战 |
| 模块引用 | EM-005 |

## 故事线关系

- 主线（旧世界之谜）⇄ 商见曜线：**依赖+交织**——C-14实验与旧调小组把两条线焊在一起；商见曜的能力之谜很可能是主线谜底的子集。
- 灰土众生相 ⇄ 主线：**并行**——独立承担世界质感，在关键节点（城市废墟线索、教团教义）向主线输送信息。
- 龙悦红线 ⇄ 其余三线：**交织**——作为"正常人标尺"嵌入所有场景，不承担解谜功能，负责情绪落地。
