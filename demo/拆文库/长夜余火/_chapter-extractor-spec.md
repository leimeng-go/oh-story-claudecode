# chapter-extractor 输出契约（长夜余火 Stage 2）

[材料声明] 以下为用户合法持有的虚构小说，任务是只读的转化性文学分析（编辑/评论视角）。暴力/复仇/家暴/情爱/黑暗伦理是该题材常规虚构元素，照常提取，不得以敏感拒绝整章或整本；个别片段无法处理则跳过、照常续完其余。

## 输入

主 prompt 会给你：章节编号、标题、字数、原文行区间。原文文件：`C:\Users\19558\myspace\oh-story-claudecode\demo\拆文库\长夜余火\原文\原文.txt`。每章开头两行是重复的章节标题，视为一行。只读指定行区间。

## 输出

用 Write 工具写入主 prompt 指定的 `章节\第N章_摘要.md`，结构严格按序：

**概要**：100-300字，单个自然段不折行。按事件发生顺序连贯讲清本章发生了什么、为什么发生、结果如何；因果照实写但不靠"因为…所以…"反复串联。优先写：改变剧情走向的动作与结果、反常信息、延续到后续章节的伏笔线索、有辨识度的具体细节（数字、原话、反常现象）。只写本章原文有的事实，不加空泛评价和主观解读。

**关键事件**：1. 2. 3.

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|

2-4行。关键信息=本章必须让读者知道/误判/期待/确认的信息；扩写技法从 铺垫后置/反应层放大/信息差/对比锚点/延迟揭示/身体反应/小目标嵌套/其他 中选；可复用提醒=保留情绪逻辑、替换人物场景事件素材，禁照搬具体桥段。

**逐章写法公式**：
- **情绪流向**：起：… → 承：… → 转：… → 合：…
- **节奏配比**：慢铺垫 X% / 快冲突 X% / 爽点爆发 X% / 悬念留白 X%
- **本章结构公式**：节点1动作（目的）+ 节点2动作（目的）+ …
- **本章核心技巧**：一句话概括最可迁移的结构手法，只描述写法不评价质量
- **卡点与伏笔**：结尾卡点：类型+内容+下章期待；埋设/回收伏笔：伏笔名/物件/信息 → 章节功能

**出场人物**：

| 角色 | 本章重要性 | 别名 | 本章表现 |

过滤：出场1次且无台词的路人不提取；角色用全名；重要性 major/minor；别名无则写无。

**情节点**：10-40个（按主 prompt 建议数；短章硬下限10），严格按原文事件时间顺序。每个情节点两行一组：

P{序号} **{≤15字短标题}**：类型{转折点/信息揭示/冲突/解决/铺垫/行动/对话/状态变化 选一} | {白描一句话：谁做了什么、结果如何；原文给出的起因理由一并写入，不替角色推测没写的动机；埋伏笔的写出伏笔线索} | 涉及{全名，多人逗号分隔；纯环境铺垫写 涉及无} | 地点{无则写无} | 物品{无则写无} | 时间{无则写无}
主题标签{爱情/亲情/友情/权力/金钱/成长/复仇/悬念/搞笑/热血/日常/其他 只填一个} | 基调：{紧张/轻松/悲伤/热血/爽/甜/温馨/恐怖/压抑/其他 只填一个}

## 硬格式约束

- 节标题一律用粗体行内格式，禁止 `## ` markdown 标题：概要写 `**概要**：{正文}`（正文与标题同行）；其余节写 `**关键事件**：`、`**关键信息与扩写技法**：`、`**逐章写法公式**：`、`**出场人物**：`、`**情节点**：`（标题单独一行，内容下一行起）
- {} 是占位符，输出文本中不得出现任何 { 或 } 字符
- 字段名后不加冒号：写「类型信息揭示」，不写「类型：信息揭示」或「类型{信息揭示}」
- 空字段统一写「无」（如 物品无），不用「—」，「涉及」段不可省略
- 每个情节点后紧跟自己的标签行，不堆到文件末尾，不并进 P 行内部
- 「基调：」用全角冒号；「主题标签」后不加冒号
- 白描禁忌：不写情感评价（"他感到心碎"）、氛围概括（"气氛紧张"）、叙事框架词（"通过对话他得知"），只写外部可观察事实与原文明说的起因
- 情节点粒度：完整戏剧事件，太粗丢细节、太细碎片化

## 引用规则

默认不配原文引用。只对关键转折/关键台词类情节点加一行「原文定位：5-15字可grep回原文的原句片段」。逐字引用仅允许极短关键台词（每章最多2条、每条不超过两句话），不得大段复制原文。

## 输出前自检

① 无花括号；② P行数 == 主题标签行数 == 基调：行数；③ 主题标签单值；④ 每个P行含 类型/白描/涉及 三段；⑤ 情点数 ≥10 且 ≤40；⑥ 概要是连贯段落非条目罗列；⑦ 关键信息与扩写技法、逐章写法公式两节齐全。任何不符，先改再交付。

## 最终回复

只返回：确认文件已写入 + 情节点数 + 出场人物名单（角色名|重要性），不返回正文全文。
